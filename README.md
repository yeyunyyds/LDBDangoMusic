# L4D2DangoMusic

此实验分支合并 LX 控制、Steam 进度同步和已验证的网易云原生通道。一起听仅限 LX；网易云独立显示歌词，不发布或应用进度。默认包为单 DLL，无需 .NET。[下载合并测试包](https://github.com/yeyunyyds/LDBDangoMusic/raw/refs/heads/zip/L4D2DangoMusic-0.9.5-combined.zip) · [一起听配置与 API](docs/sync/README.md) · [网易云说明](docs/multi-platform-lyrics.md)

> 当前正式版：[v0.9.5](https://github.com/yeyunyyds/LDBDangoMusic/releases/tag/v0.9.5)。提供普通世界/屏幕歌词、场景挂画，以及可选的手动/自动实体跟随；支持平滑移动、原生 HUD 菜单和可选彩色效果。

为《求生之路 2》（Left 4 Dead 2）提供音乐歌词显示的 L4N 插件。通过兼容 LX / BLF 的本地音乐 API 获取播放进度和歌词，在游戏中呈现带逐字动画的歌词，并支持世界空间定位、歌名与作者显示以及游戏内调节。

插件由 L4N 加载，在 **32 位游戏进程**中直接读取 Source Engine 相机信息并使用 D3D9 绘制。运行依赖为 L4N 和音乐播放器的本地 API，不需要 LDB 或 DXVK。

## 功能

- 同步显示 LRC / LX 歌词，支持逐字时间信息及翻译。
- 场景挂画：支持墙面和地面，自动搜索或手动放置，各句独立停留、淡出；可选在无新表面时按顺序复用已有挂画。
- 挂画文字布局：独立调整歌名、作者、歌词（含翻译）的左右、高度、大小和离表面距离，提供固定预览；地面文字可选随视角转向。
- 世界空间歌词：歌词随相机移动产生视差，也可使用屏幕显示模式。
- 支持 1～9 个歌词位置依次轮换，分别调整高度、左右、距离和大小。
- 歌名、作者独立显示与定位，歌词支持整体位置调节。
- 保留六套颜色预设，另提供四套新配色、双色渐变、逐字彩虹、流动渐变和双色呼吸；支持自定义颜色、柔光、逐字弹跳和抖动。
- 手动锁定实体持续显示歌词，或按类型自动追踪范围内最近的特感、队友、物品等网络实体；类型规则可保存。
- 实体平滑默认开启，可选全局换句移动与多种曲线，实体字幕和普通歌词的退场规则相互独立。
- 通过 L4N 菜单实时设置，支持固定内容预览、动画预览、位置重置与配置保存。
- 支持暂停、恢复播放、换歌及播放器断开后的重新同步。

本插件负责显示歌词，不播放音乐，也不提供音乐资源。

## 运行要求

- Windows 版《求生之路 2》。
- 已安装并正常工作的 L4N，支持插件接口 v2 的 HUD 菜单功能。
- LX / BLF 本地 API，或能向 Windows SMTC 提供歌曲、时长和进度的音乐客户端；Windows 会话桥接要求 Windows 10 2004+ x64。

默认连接 `127.0.0.1:23330`。不同播放器版本提供的 API 可能不同，请先确认所用版本支持上述接口。

世界空间模式依赖受支持的 Source 相机接口与游戏构建；无法取得有效相机信息时，插件会回退到屏幕显示。普通世界空间歌词不提供墙体遮挡；场景挂画使用世界几何射线做整幅遮挡检查，范围和限制见挂画指南。

## 安装

[下载 L4D2DangoMusic v0.9.5](https://github.com/yeyunyyds/LDBDangoMusic/releases/download/v0.9.5/L4D2DangoMusic-0.9.5-l4n.zip) · [Release 说明](https://github.com/yeyunyyds/LDBDangoMusic/releases/tag/v0.9.5)

安装压缩包内仅包含 **bin 文件夹和 README.md**，不附带源码、构建工具、测试程序或额外依赖。

1. 退出游戏，确认 L4N 已安装并正常工作。
2. 将压缩包内的 `bin` 文件夹合并到游戏根目录。
3. 首次安装复制全部文件。多平台测试包升级时保留已有的 `config.json`。网易云原生小包只替换 DLL，选择“音乐来源 → 网易云音乐”；完整 SMTC 包还需替换配置子目录内的 `DangoMediaBridge.exe`。
4. 完整重启游戏，在 L4N 菜单进入 L4D2DangoMusic。

安装路径：

```text
bin/neko/plugins/L4D2DangoMusic.dll
bin/neko/plugins/L4D2DangoMusic/config.json
bin/neko/plugins/L4D2DangoMusic/DangoMediaBridge.exe  # 多平台测试包
```

源码和构建脚本维护在 [`main` 分支](https://github.com/yeyunyyds/LDBDangoMusic/tree/main)，[`zip` 分支](https://github.com/yeyunyyds/LDBDangoMusic/tree/zip) 仅提供安装压缩包。

从源码构建的用户仍可使用 `scripts/install.ps1 -GameRoot "游戏根目录"` 安装；运行目录为源码根目录。安装包用户直接复制 `bin` 即可。

请只保留一份启用的歌词插件。旧的 `LDBDangoMusic.dll` 和改名副本应移出加载目录，否则可能出现两份歌词或菜单分别控制不同副本的情况。

## 使用与设置

1. 启动音乐播放器，使用 LX 时开启本地 API；使用网易云等 Windows 客户端时选择“显示与歌词信息 → 音乐来源”。
2. 启动游戏，在 L4N 菜单中选择 **L4D2DangoMusic**。
3. 按需调整显示、翻译、预设、颜色、动画及同步偏移。
4. 点击 **保存设置**，使修改在下次启动时继续生效。

进入 **位置与数量** 页面后，实时歌词会暂时替换为固定的歌名、作者和编号歌词，方便调节位置；音乐仍继续播放。各级页面均可选择 **保存设置并结束预览**，恢复当前歌曲的歌词显示。

默认使用两个轮换位置，歌词位于屏幕中心稍上方，长句自动回到视野的功能默认关闭。换句复用世界位置时，旧锚点必须仍在视野内，且到相机的距离小于该歌词位置配置距离的 3 倍；超出时按预设重新放置。可在“显示与歌词信息 → 世界位置与回归 → 复用距离上限”选择 1、1.5、2、3（默认）、4、5 或 10 倍。位置复用与长句回归同时开启时，计时到达后仍可见且未超出复用距离上限的歌词保持原位，不再被定时回归覆盖。歌名和作者可在显示菜单中分别开启。

主菜单默认共 8 项：歌词显示、显示与歌词信息、位置与数量、歌词颜色、动画与停留、场景挂画、保存设置、更多设置。单行长度与同步偏移位于“显示与歌词信息”；颜色预设、正文颜色、光晕颜色与柔光合并在“歌词颜色”。颜色预设仅更改配色和柔光，手动修改后显示“自定义”，不重置动画。

菜单默认位于左侧、垂直居中，可手动移动并保存。升级时原默认顶端位置自动迁移，自定义高度保留。“菜单外观 → 调整菜单位置 → 重置到默认位置”可恢复居中。

菜单由插件原生 HUD 绘制，L4N 仅提供入口。设置即时生效，当前值逐帧刷新，返回父页也显示最新状态，不会因开关或调参数叠加层级。

- `1..9`：选择当前页项目；`-` / `=`：上页 / 下页。
- `0`：返回一级，根页关闭；`Esc` 或 `/`：关闭并退出位置预览。
- “更多设置 → 菜单外观”提供深黑、烟灰、石墨、高透明四套背景；选中透明度或字号后用 `-` / `=` 调节，位置页用方向键移动。
- 默认从 L4N 进入，F10 默认关闭，可在外观页启用。菜单外观和歌词设置均通过主菜单“保存设置”持久化；任何实际修改都会标记 `[未保存]`，写入成功后显示 `[已保存]`。

仅在菜单打开且游戏窗口获得焦点时读取菜单按键，入口按键释放后才接收下一次操作；不捕获鼠标或 WASD。

挂画背景默认关闭，可在“场景挂画 → 挂画外观与维护 → 背景面板”开启；升级时保留已有配置中的选择。开启 **场景挂画歌词** 后，可选择自动寻找表面，或用 F8 手动放置。挂画外观与维护页可选择墙面/地面、编辑文字布局，以及开启默认关闭的地面文字随视角转向。找不到新表面时，可选择按创建顺序复用视野内、未遮挡且未超距的已有挂画。挂画参数、旧句停留、背景、固定世界歌词回退及完整设置说明见 [场景挂画指南](docs/wall-experiment-guide.md)。

“靠近时后退”作用于悬浮世界歌词、悬浮歌名和作者；进入该组件配置距离的 60% 以内时持续推远。固定墙面挂画保持贴墙。无逐字时间轴的“估算渐显”独立生效，短句、无空格长词也会分字渐显；统一词条起点等于整句起点、没有进一步细分的数据也按无细分时间处理。

“显示与歌词信息 → 世界位置与回归 → 长句回到视野 → 自定义秒数”提供 ±0.1、±1、±10 秒调节，最大 300 秒，0 为关闭；保留 3/5/10 秒预设，修改后可保存设置。

### 实体跟随、自动追踪与彩色效果

- **更多设置 → 实体持续跟随歌词**：对准物品或角色锁定后，歌词持续跟随目标；可调整位置、大小及整句上下往复。实体字幕每次只显示当前一句，原文和翻译一同替换，避免旧句叠加。
- **更多设置 → 自动实体追踪（永久规则）**：按特感、队友角色、物品和其他实体分类，选择范围内最近的有效目标。支持瞄准识别、每类开关和分类一键开关；默认全部关闭。保存后跨游戏保留类型规则。
- 一键开关显示“开启／部分开启／关闭”：全关时点击全开，部分或全开时点击全关。绿色表示开启、红色表示关闭、黄色表示部分开启，子菜单入口为白色。
- **动画、速度与停留 → 歌词移动与实体平滑**：实体平滑默认开，全局换句移动默认关；提供先快后慢、匀速、先慢后快、缓入缓出和回弹。
- **歌词颜色 → 彩色、混色与渐变**：新效果默认关闭，可选新配色并调整混色强度和流动速度，保存后保留；选择原有预设可恢复纯色。
- 显示顺序为有效手动实体 → 有效自动实体 → 挂画 → 普通歌词。没有实体时按设置回退；普通歌词和挂画仍自然停留、淡出，只有实体上的当前句即时替换。
- 启用跟随后，主菜单第 9 项可一键“返回普通歌词”。主菜单第 7 项仍为保存设置。

[实体跟随指南](docs/entity-follow-guide.md) · [动画与自动追踪指南](docs/animation-and-auto-follow.md) · [菜单与配色指南](docs/colors-and-menu.md)

实体接口依赖受支持的游戏构建，使用网络姿态与近似高度；不包含精确骨骼、静态地图道具枚举和动态遮挡。角色台词采集不包含在本版本中。

### 配置文件

配置路径为 `bin/neko/plugins/L4D2DangoMusic/config.json`。通常使用游戏内菜单即可；手动编辑配置时，请先退出游戏。

| 配置项 | 用途 | 默认值 |
| --- | --- | --- |
| `musicSource` | 0 自动，1 LX，2 Windows，3 网易云，4 QQ，5 酷狗，6 Spotify，7 Tidal | `0` |
| `port` | 本地音乐 API 端口 | `23330` |
| `demo` | 使用离线示例歌词 | `false` |
| `translation` | 显示翻译 | `false` |
| `worldLyrics` | 使用世界空间显示 | `true` |
| `offsetMs` | 歌词同步偏移，正值提前 | `500` |
| `layout.lyricCount` | 歌词轮换位置数量 | `2` |
| `reuseDistanceFactor` | 可见旧锚点的复用距离上限倍率，分别乘以各歌词位置配置的距离 | `3` |
| `reanchorMs` | 长句回到视野的间隔，`0` 表示关闭 | `0` |
| `wallEnabled` | 启用场景挂画 | `false` |
| `wallAutomatic` | 自动寻找所选表面；关闭为手动位置轮换 | `true` |
| `wallSurface` | 放置表面：`0` 墙面、`1` 地面 | `0` |
| `wallReuse` | 无新表面时按创建顺序复用已有挂画 | `false` |
| `wallFloorFollow` | 地面文字随视角转向，落点保持固定 | `false` |
| `wallBackdrop` | 显示挂画背景 | `false` |
| `wallLayout` | 歌名、作者、歌词在挂画内的独立布局 | 见配置示例 |
| `hudAppearance.centerY` | 菜单默认垂直居中 | `true` |
| `wallCapacity` | 挂画数量上限 | `6` |
| `wallLingerMs` / `wallFadeMs` | 旧句额外停留 / 淡出时间 | `4000` / `1000` |
| `wallFallback` | 新句找不到可用表面时使用固定世界歌词 | `true` |
| `showTitle` / `showArtist` | 显示歌名 / 作者 | `false` |

完整配置见 [config.example.json](config.example.json)，视觉预设见 [presets](presets/)。如需独立检查显示效果，可使用游戏内预览，或将 `demo` 设为 `true`。

### 问题排查

- **没有歌词**：LX 请检查本地 API；其他客户端请确认 Windows 媒体控件有当前歌曲和进度，且安装了桥接 EXE、选择了正确来源。正常播放模式在暂停、停止或断开时会隐藏歌词。
- **歌词有提前或延后**：在菜单中调整同步偏移；正值使歌词提前，负值使歌词延后。
- **出现双份歌词**：检查 L4N 插件目录，移出旧副本后完整重启游戏。若曾安装旧版 Host 歌词插件，也需停用该副本并重启对应 Host。
- **动画不明显**：部分预设会关闭动画，可选择“恢复默认动画”，再进入“动画预览”检查。

菜单中的 **版本、路径与播放器诊断** 可查看实际加载的 DLL 路径和播放状态。日志位于 `bin/neko/plugins/L4D2DangoMusic/L4D2DangoMusic.log`；反馈问题时，请附上日志、插件版本和复现步骤。

## 从源码构建

### Windows / MSVC

安装 .NET 8 SDK 和 Visual Studio C++ 构建工具，在 **x86 开发者 PowerShell** 中进入源码根目录并运行：

```powershell
.\scripts\build.ps1
```

生成文件位于 `build` 目录。构建使用项目内附带的 SDK 头文件，无需提供游戏 DLL。

### Linux / MinGW

安装 .NET 8 SDK、支持 C++17 的 GCC、Python 3，以及 i686 MinGW-w64 POSIX 工具链：

```bash
bash scripts/test.sh
bash scripts/build-mingw.sh
dotnet publish media-bridge/DangoMediaBridge.csproj -c Release -o build/media-bridge
```

可通过 `DANGO_CXX` 环境变量指定 MinGW 编译器路径。Windows D3D9 验证程序可通过 `scripts/smoke.ps1` 运行；打包使用 Python 3：

```bash
python scripts/package.py
```

最小安装包输出到 `build/packages`。包内只包含 `bin/` 与 `README.md`；许可和对应源码链接写入安装说明。生成后将安装包单独发布到 `zip` 分支。

跨平台回归测试和交叉编译不能替代实际 L4N 游戏环境验证。
