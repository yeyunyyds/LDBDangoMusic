## L4N 菜单

从 L4N 插件菜单进入 L4D2DangoMusic：

- 总开关。
- 显示与歌曲信息：翻译、世界歌词、靠近时后退、远处歌名/作者、长句回到当前视野。
- 六套预设：暖白浮光、轻柔舒缓、霓虹粉、冰蓝、琥珀金、简洁纯净。
- 颜色与柔光：正文和光晕调色板、每通道 0~255 RGB 自定义（±1/±16 与常用值）、柔光开关。
- 动画与停留：显字动画 0.5/0.75/1/1.5/2x，抖动与弹出开关，退场耗时 200~1500ms，换句后额外停留 0~2000ms。
- 同步偏移：±50/100ms，或重设为500ms。显字动画速度不改变歌曲/演唱时间线或播放器速度。
- 保存：后台原子替换配置并保留 config.json.bak；重新打开插件菜单查看上次保存结果。未保存的改动仅在本次运行生效。

菜单通过 SDK KeyValues callback/user_data 实现。MinGW 的 MSVC 虚表适配也已转发 RequestHudMenu。
所有菜单编辑通过不可变配置快照传给渲染线程；文件写入在后台，不在绘制回调中做配置 IO。
原有端口与时间偏移在预设切换时保留。预设默认重置视觉参数；自定义修改可再次保存。
JSON 中未知字段在保存时保留。手动编辑配置需重启，不提供并行文件热编辑合并保证。

## 长句与停留

默认 lingerMs=1000：下一句开始后旧句完整保留1秒，再用 transitionMs（默认400ms）淡出。
默认 reanchorMs=3000：同一句持续不换时，每3秒重新放到当前视野前方，复用同一个实例，不重新播放显字动画。
菜单可选择关闭、3/5/10秒。退场的旧句不会重新定位。
远处歌名/作者使用独立的单一世界锚点；没有有效相机时以顶部屏幕文字回退。

## 瞬间重影修正

代码检查发现并针对以下机制修正，但没有在云端复现用户的游戏画面：

1. 非嵌套 Device/SwapChain 多次 Present 可能重复在同一 backbuffer 上叠加。新增按呈现目标的规范 IUnknown 身份 + 场景写入代次去重（Device 主链与 SwapChain 路径归一）；只有游戏 EndScene/目标 Clear 成功才产生新代次，插件自己的 Begin/EndScene 不计入。
2. 歌曲进度在句首附近回跳，可能创建同一句的第二个退场实例。现在同索引/文本复用，重复文本旧实例移除。
3. 靠近时后退不再永久改写世界锚点，仅计算当前帧展示位置，避免来回移动累积位置变化。
4. 3秒回屏复用原实例，不生成另一份；新旧安装迁移也会停用旧 DLL。

连续不同歌词的交替保留属于设定行为，默认最多4句；同一句在同画面被绘制两份才是本次修正目标。
多设备/任意第三方渲染路径仍不属于已验证范围。
