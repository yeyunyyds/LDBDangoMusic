# 场景挂画歌词 · v0.9.4

把歌词固定在地图墙面或地面上，按表面朝向绘制。墙面文字保持原来的世界位置与方向；地面文字默认同样固定，也可选择随视角转向而不移动落点。场景挂画及背景默认关闭。

## 开始使用

1. 安装 L4N 和本插件，启动播放器本地 API，播放带歌词的歌曲。
2. 进入地图，在 L4N → L4D2DangoMusic → 场景挂画歌词开启挂画，保持“内容：歌词轮换”。歌词显示总开关也要开启。
3. 默认自动寻找墙面。需要地面时，到“挂画外观与维护 → 放置表面”选择地面。
4. 关闭菜单正常游戏。每句优先寻找新表面，找到后固定在该位置；旧句按停留与淡出设置自然消失。
5. 满意后返回主菜单第 7 项“保存设置”。位置坐标不跨地图保存，功能开关、布局与参数会保存。

默认旧句额外停留 4 秒，再用 1 秒淡出；最多保留 6 幅，达到容量时可以提前移除最早一幅。当前句未切换时保持显示，暂停、停止、断开或播放会话改变会清理歌词。

## 自动放置、复用与回退

墙面搜索在前方左右约 35°、55°及正前方尝试；换句交替优先侧，方向保持水平，低头看路不会误放到地面。地面模式则搜索前下方，接受朝上的地面和较缓斜坡，拒绝天花板。每 200ms 最多尝试一个方向。

候选矩形经过 3×3 表面支撑采样、5 条视线检查、间距及矩形重叠检查。放置后中心、法线及初始朝向固定，后续新句继续寻找新位置，不会无限向远处延伸。

“无新表面时复用旧挂画”默认关闭。开启后，完整一轮五方向搜索失败时，按创建顺序从最早仍保留的挂画起循环复用，跳过视野外、遮挡、可见性数据过期及超出搜索距离的目标。复用仅替换为当前句，保留平面与 ID；已经淡出删除的自动挂画不会复活。

“新句无表面时固定世界歌词”默认开启。约 1 秒仍未分配到新表面或可复用挂画时，本句选择悬浮世界歌词；相机不可用时回退到屏幕显示。显示路线按句锁定，不会在稍后找到墙面时突然移动。成功贴面的当前句即使离开视野也保持在原位，不改成悬浮歌词；下一句重新选择。其他旧挂画继续自然停留、淡出。

长句回归、悬浮位置复用与靠近时后退不移动贴面的挂画；只有该句已经回退到悬浮显示时，才使用悬浮定位规则。

## 手动放置

将放置方式切为“手动挂画轮换”，对准所选类型的合适表面按 F8；也可在菜单选择“手动放置：3秒后按准星”，关闭菜单后瞄准。放置会进行支撑与可见性检查。

后续歌词在已放置、可见的手动挂画间轮换，这一路径不依赖自动复用开关。播放会话重置时手动位置保留、内容清空；切图、切换表面或清空全部挂画会清除位置。

## 文字布局和地面转向

“挂画外观与维护 → 挂画文字位置与大小（固定预览）”分别调整歌名、作者、歌词（原文与翻译为一组）的左右、高度、大小和离表面距离，支持单组件和全部重置。进入时显示固定示例，暂时替代真实歌词；退出、关闭菜单或保存并结束预览后恢复。

左右/高度相对于挂画矩形，高度从上边缘计算。离表面距离是文字向表面外侧的偏移，不是整幅挂画到相机的距离。默认布局延续旧版外观，详细范围和配置见 [挂画布局说明](wall-reuse-layout.md)。悬浮歌词的位置设置与挂画布局互相独立。

“地面文字随视角转向”默认关闭。开启后，地面文字布局随相机转向，挂画中心、法线及背景保持固定；墙面不受影响。大幅放大或移动文字可能超出原支撑矩形，现有检查不是逐字、逐像素遮挡。

## 参数与操作

| 参数 | 菜单选项 | 默认值 |
| --- | --- | --- |
| 新挂画尺寸 | 80×28、120×40、180×60 世界单位 | 120×40 |
| 最多挂画 | 2、4、6、8 | 6 |
| 搜索距离 | 300、600、900 世界单位 | 600 |
| 最小间距 | 80、140、220 世界单位 | 140 |
| 旧句额外停留 | 0、2、4、8 秒 | 4 秒 |
| 淡出耗时 | 0.5、1、2 秒 | 1 秒 |

参数立即生效，页面数值实时刷新。`1..9` 选择、`0` 返回、`Esc` 或 `/` 关闭，`-` / `=` 翻页。设置变更仍会重建歌词会话，清理旧句内容。

颜色、翻译、逐字显字、单行长度、弹跳、抖动及歌名/作者开关沿用普通歌词设置。背景面板和调试标识默认关闭。“清空全部挂画”删除放置位置，等待下一句再自动搜索；关闭挂画恢复普通歌词。

## 支持范围与诊断

插件使用经支持构建验证的 Source 相机和 EngineTraceClient003，不依赖 LDB/DXVK，也不读取完整地图网格。

- 当前射线针对世界几何，不将静态模型、动态门或角色当成挂画表面，也不保证这些物体能遮挡文字。
- 拒绝玻璃、天空、nodraw、未命中或起点在实体内的结果；地面模式也拒绝天花板。
- 支撑与遮挡采用有限采样，整幅隐藏，不是完整网格或逐像素深度测试。
- 每 50ms 最多更新两幅挂画的视线，超过 350ms 的结果隐藏；每次搜索最多 15 条射线。
- 与近裁剪面相交时整体跳过；接口对象、虚表或构建不匹配时停止调用射线接口。

日志位于 `bin/neko/plugins/L4D2DangoMusic.log`，挂画行带 `Wall experiment:` 前缀。可从菜单诊断页确认实际 DLL、播放器状态及版本。

本次正式发布包含已由用户验收的位置修正、菜单居中、挂画复用/布局/地面功能。实体挂载和 NPC 台词不在正式版中。云端完成可移植回归与 Windows x86 交叉编译，不运行真实游戏。
