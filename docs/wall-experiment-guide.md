# 墙面挂画实验版 0.8.1-wall2

本包来自 `experiment/wall-mounted-lyrics` 分支。实验功能默认关闭，普通歌词保持原有模式。它不是自动沿通道布置版本；上一版固定墙面示例已实机确认可见，本轮接入真实歌词、翻译和显字控制。

## 安装和试用

1. 退出游戏，使用包内 `source/scripts/install.ps1` 安装，避免同时加载旧 DLL。保留原配置即可。
2. 启动游戏并进入地图，打开 L4N → **L4D2DangoMusic 0.8.1-wall2 → 实验：墙面挂画**。
3. 打开“墙面实验”。主菜单“歌词显示”总开关也需要开启。
4. 关闭菜单，准星指向一块足够大的平整墙面，按 **F8** 放置。
5. 也可以选择“3秒后按当前准星放置”，在3秒内退出菜单并瞄准墙面。
6. 前后走动、左右侧身、转头观察。挂画的位置和朝向应保持不变，斜看时产生透视缩短，背面不可见。

F8 是本实验的固定热键。如与其他插件绑定冲突，使用菜单的3秒放置入口。插件不会取消游戏或其他插件原有的 F8 行为。

菜单提供小/中/大三种尺寸（世界单位80×28、120×40、180×60），仅影响下一幅。最多保留4幅，继续放置会移除最早一幅。
“清空全部挂画”移除已有挂画。关闭实验会恢复普通歌词；实验开关、放置面板和示例/歌词选择不保存；背景面板、调试标识可以随普通设置保存。切图时清空挂画。

## 内容与位置

默认显示固定示例文字，便于不依赖音乐播放器验证。切换“当前歌词”后，所有测试挂画同步显示当前句；暂停/断开或无有效歌词时隐藏挂画内容，不继续展示旧歌词。
当前歌词支持逐字时间轴与翻译，沿用普通歌词的显字和入场控制；无逐字时间轴时默认整句，可选择估算渐显。尚未分配不同的歌词历史或自动沿墙轮换位置。

挂画不使用普通歌词的“靠近后退”和“长句回屏”逻辑。已放置的挂画不根据后来相机朝向或射线结果重新旋转。
实验开启后替代普通歌词显示，位置调节页的预览仍优先显示；测试完请关闭实验恢复正常显示。

## 范围与遮挡

- 只接受已知构建的 `EngineTraceClient003`。接口对象、虚表条目、关键函数指令和现有游戏构建校验通过后才调用。
- 射线只在 Source `View_Render` 回调的原始函数返回后执行，不在 Present 绘制或网络线程里调用。
- 地面、天花板、玻璃、天空、nodraw 表面、未命中和起点在实体内的结果不作为放置墙面。
- 放置时对中心、角点和边缘做3×3网格射线采样，拒绝明显跨门洞或拐角的位置。这是有限采样，不能严格证明整个矩形没有小洞。
- 每100ms最多为4幅挂画各检查5条视线；任一采样点被世界几何阻挡就隐藏整幅挂画。遮挡更新存在最多约100ms采样延迟。
- 这是保守的整幅隐藏，不是逐像素深度遮挡。门框挡住一角也可能使整幅挂画消失。
- `TRACE_WORLD_ONLY` 不测试静态道具或动态角色、门等实体；这些物体不能作为放置表面，也不保证能遮住挂画。
- 当前近裁剪面相交时整体跳过，不支持文字部分穿过近裁剪面的多边形裁剪。
- 相机或挂画快照失效时不继续画旧画面；切图后重新放置。

## 诊断

默认隐藏调试标识。在墙面菜单开启“调试标识”后，画面顶部显示 `WALL`、F8提示、面板数和状态。若放置失败，先尝试更大、更平整的实墙或选择小尺寸。

日志仍为 `bin/neko/plugins/L4D2DangoMusic.log`。相关行带 `Wall experiment:` 前缀，包括接口绑定、首次结果校验、命中点、法线、表面标志和面板尺寸。

- `Trace interface/profile mismatch`：当前接口或游戏构建与已核对资料不符，不调用射线接口。
- `Trace result validation failed`：结果区边界、字段或几何一致性校验失败，暂停后续调用。关闭再打开实验可以重试；反馈时附完整日志。
- `Wall is not a supported flat 3x3 patch`：平面法线、网格支撑或表面范围不满足条件。
- `Waiting for an active Source camera`：尚未取得游戏相机，请确认已进入受支持的地图场景。

## 验证状态

本分支已有可编译的接口接线、手动放置、文字平面绘制和遮挡采样代码，不再仅是投影数学原型。
静态指令证据见 [trace-abi-evidence.json](research/trace-abi-evidence.json)，可用 `python scripts/verify_trace_abi.py engine.dll` 复核；不执行游戏二进制。

Linux回归覆盖布局、结果区哨兵、数据一致性、平面透视、墙面支撑和遮挡策略。Windows x86构建包含 `source_walls_abi_test.exe`，使用模拟对象验证调用约定和过滤器虚表；它不是实际引擎验收。
云端没有执行 Windows / D3D9 / L4D2；上一版固定示例已有用户实机反馈正常显示。本版新增的歌词动画绘制未在云端进行游戏验收。运行本实验包后，首先确认日志出现 `First TraceRay result passed validation`，再验收固定位置、斜视、遮挡与切图。

本版歌词显示、渐显、翻译、背景与调试开关说明见 [歌词设置](0.8.1-lyrics-controls.md)。上一版墙面示例已经用户实机确认可显示；本版新增逐字墙面绘制仍需实机验证。
