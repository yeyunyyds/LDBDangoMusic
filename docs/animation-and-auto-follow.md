# 退场、移动动画与自动实体追踪

这些功能自正式版 v0.9.5 起提供，不包含角色台词采集。

## 显示与退场的优先度

在歌词显示开启、且没有固定预览的情况下：有效手动实体 → 有效自动实体 → 已开启的场景挂画 → 普通歌词。普通歌词遵循原有世界/屏幕模式设置。实体无效、离开检测范围或缺少可验证姿态时回退，自动规则继续检测。第一人称自身角色一般不能在头顶显示，自动角色筛选会避开与当前相机重合的第一人称位置。

| 实际显示路径 | 换句行为 | 时间设置 |
| --- | --- | --- |
| 实体字幕 | 单句即时替换，原文和翻译一同移除，无旧句停留/退场 | 与普通退场设置隔离 |
| 普通世界/屏幕歌词 | 旧句停留后淡出；位置编号复用也不提前销毁旧句 | 全局“停留与退场” |
| 场景挂画 | 保留旧句面板至淡出完成，复用也等待旧内容结束 | 默认跟随全局；显式开启“挂画独立停留与退场”后使用挂画参数 |

实体跟随的开关、位置设置及自动规则变化不再清空普通歌词或挂画缓存。世界/挂画切换到实体时，已经存在的普通句子仍完成自己的退场，只有实体上的句子立即替换。挂画数量限制优先清理空面板，不能为新句直接覆盖仍在淡出的内容；保留的退场实例有 32 份安全上限。

暂停、停止、播放器断开、切歌、切图、拖动播放进度、进入固定预览等仍需要立即清理，避免把旧歌或旧地图的内容留在新场景。修改颜色等外观不再重置句子生命周期；每个普通旧句在退场时记录自己的停留和淡出时长。

## 移动动画

“动画、速度与停留 → 歌词移动与实体平滑”提供：

- 实体移动平滑：默认开；也可在实体“位置与大小”页独立开关。
- 全局换句位置移动：默认关。新句从上一句当时的显示位置开始，移动到自己的编号位置；支持 1～9 个编号轮换。旧句仍独立淡出。此移动用于普通世界/屏幕歌词，不移动固定墙面/地面挂画。
- 曲线：先快后慢（默认）、匀速、先慢后快、缓入缓出、回弹。
- 默认耗时 350ms，菜单每次调整 100ms，范围 100～2000ms。实体与普通移动使用共同曲线/耗时，各自开关独立。

实体平滑只修改文字位置，不改变实体或碰撞。换目标、换地图、长时间快照中断和大幅传送会重新定位，避免文字从另一个角色飞过来。整句上下往复在平滑之后叠加，原文和翻译使用同一个锚点。

## 自动实体追踪

入口：“更多设置 → 自动实体追踪（永久规则）”，或实体跟随页末项。默认自动追踪关闭，所有类型未选中。

类型按特殊感染者、队友角色、武器/物品、其他实体分组，使用原生 HUD 的 `-` / `=` 翻页和数字键选择。包含 Tank、Boomer、Zoey、Gnome 等预设；“其他”还会列出当前读到的新网络实体类，以及配置中已保存的类。

- 选择类型可单独开关；首次开启一个类型会同时开启自动追踪总开关。
- 范围内有多个符合规则、存活且姿态可用的实体时，选择距离相机最近的一份；多个类型同时启用也按距离选择。
- 总开关关闭会保留所选类型；总页和各分类第一页都提供“一键开关：[开启／部分开启／关闭]”：全部关闭时按一下全开，只要部分或全部开启，按一下就全关。分类按钮只修改本分类，其他分类不受影响。全部开启仅覆盖当前已列类型，不自动泛收未来未知类。
- “瞄准识别并设置类型”可对准对象，查看语义类型/网络类，单独开启或关闭。该页也可调检测范围，默认 1200 游戏单位，范围 100～4000。
- 自动追踪页最后一项“保存设置”，或主菜单“保存设置”，写入后跨游戏生效。未保存提示沿用原菜单。手动目标的完整句柄仍仅本次会话有效，永久保存的是类型规则，不是上一局的实体编号。
- 主菜单“返回普通歌词”停止手动和自动跟随，保留所选自动类型，便于以后重新开启。

自动角色识别使用角色字段/感染者类别，不靠玩家昵称；角色文字使用近似头顶高度再叠加实体位置偏移，不是精确骨骼。常规扫描每 200ms，选中目标及父级约每 33ms 更新一次。完整句柄、地图 epoch、父级、休眠、存活和快照时效检查仍保留。

当前只处理网络实体，不包含静态地图道具。Gnome 的物理道具表示需要模型名，或本地图已经观察到的 CGnome 世界模型编号；模型查询不可用且尚未建立该关联时，不把任意物理道具猜成 Gnome。其他未知类也只有取得有效网络姿态后才能挂载。

## 配置

`entitySmooth=true`、`lyricMove=false`、`moveCurve=0`、`moveMs=350`。`wallIndependentTiming=false` 表示挂画沿用全局停留与退场。新增自动规则默认：

```json
"autoFollow": {"enabled": false, "range": 1200, "rules": []}
```

例如只选 Tank 和 Zoey：`rules` 为 `["class:Tank", "survivor:5"]`，并将 `enabled` 设为 true。推荐通过菜单选择并保存。

实体局部位置、大小和上下往复仍沿用已有的会话设置；本次新增的自动规则及移动动画开关、预设、耗时可保存。

## 验证

可移植测试覆盖普通/实体生命周期隔离、单编号仍然淡出、挂画切换时自然退场、复用等待淡出、配置往返、最近存活实体、角色/感染者分类、范围/地图/过期拒绝、五种移动曲线、平滑及目标身份变化。Windows x86 模拟/菜单测试增加自动规则开关、保存和移动设置的真实按键路径；云端交叉编译不等于已经在游戏内验收。
