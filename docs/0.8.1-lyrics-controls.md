# 歌词设置：0.8.1-wall2

本包继续保留墙面挂画实验，默认关闭。以下控制针对普通屏幕/世界歌词；墙面挂画已接入原文、翻译、按演唱进度显字和入场动画；同样使用这些显字设置。

## 按演唱进度显字

L4N → L4D2DangoMusic → 动画、速度与停留 → 按演唱进度显字（含翻译）。默认开启，可切换为整句显示。

原文有逐字时间轴时使用接口提供的时间。只有逐行时间时默认整句显示；可在同页的“无逐字时间轴”切换为“估算渐显”。配置键 `fallbackReveal` 默认 `false`。翻译没有独立逐字时间，因此在渐显模式下按字数比例映射原文的出现时间，不代表精确的双语逐词对应。即使关闭弹跳、抖动，或使用简洁预设，时间控制仍然有效。弹跳入场和显字动画速度只控制入场动作，不改变歌曲时间。

翻译按完整文本预先排版，随后逐字显现，避免每新增一个字就左右移动；译文过长时按单行长度换行。

## 单行长度

主菜单 → 单行长度。提供 0.75、1（默认）、1.5、2、3、4 倍。只增加换行前容纳的长度，不缩小文字，也不更改组件距离。原有默认宽度和字号不变，建议长英文先尝试 1.5 或 2 倍。

配置键 `lineWidthScale` 支持 0.5–4；实际换行宽度为 `maxWidth × lineWidthScale`。过大的宽度可能使文字超出屏幕边缘。

## 换句沿用世界位置

显示与歌曲信息 → 换句沿用视野内原位置。默认开启。

每个编号位置独立保存一个世界锚点。下次轮到该位置时，锚点中心仍在屏幕可视范围内，则新句继续使用它；否则按照该编号的预设位置重新放置。关闭后恢复每次换句都按预设放置的行为。歌词仍按位置编号依次轮换，并非全部集中到一个锚点。

换歌、暂停/恢复、跳进度、切图、切换显示模式、修改设置等原有重置流程继续清理锚点，避免跨场景或跨歌曲复用。这里的“视野内”只判断投影，不判断墙壁遮挡。长句定时回归仍默认关闭；与位置复用同时开启时，计时到达后仍可见且未超出复用距离上限的锚点保持原位，移出视野或超过距离上限才回归。关闭位置复用时保留按间隔重新放置的行为。

配置键 `reuseVisibleAnchor` 为布尔值。

## 菜单即时操作与保存

点击功能开关后立即应用，并返回对应的设置页；不再显示“设置已应用”的确认页。预设、长度、同步等选择会直接返回菜单。需要下次启动保留时，仍使用主菜单的“保存设置”。

## 验证范围

已运行 Linux 回归测试，覆盖静态预设下按时显字、翻译渐显、长度不改变字宽、可见锚点复用/移出视野重放置，以及配置往返。Windows x86 DLL 和菜单/D3D9 模拟程序已交叉编译；本次修改的实际游戏观感需要实机验证。

用户已反馈上一版墙面示例正常显示，本版保留该能力。

## 挂画歌词更新

进入“实验：墙面挂画”，开启实验并选择“内容：当前歌词”，瞄准墙壁按 F8 放置。文字和翻译逐字贴在固定墙面平面上，保留透视，不跟随视角转动；抖动与弹跳在墙面内运动。颜色、翻译、歌曲信息、渐显开关沿用普通歌词菜单设置。长句会在挂画内部排版，整体缩放以适应挂画尺寸。

新增“背景面板”开关，可让文字直接显示在墙上；调试横幅和挂画编号改为默认隐藏，可通过“调试标识”开启。背景与调试标识可使用主菜单保存。暂停、断开音乐接口或无有效歌词时隐藏当前歌词挂画，避免保留旧句。

目前仍手动放置，最多 4 幅，所有挂画显示同一句当前歌词；尚未自动沿通道连续铺设。固定示例保留，实验默认关闭。
