# 诊断工具归档

诊断功能保存在 [archive/diagnostics-v0.9.8](https://github.com/yeyunyyds/LDBDangoMusic/tree/archive/diagnostics-v0.9.8)，对应 v0.9.8 发布时的源码及诊断构建脚本。

主线不再构建、打包或发布 diagnostics。MinGW 构建拒绝启用诊断变量，PowerShell 构建移除诊断参数；发布流程只构建普通 DLL，预构建发布也只要求普通安装包。打包器继续拒绝包含诊断标记的 DLL，防止误发布。

普通运行日志、正式歌词功能和自动化回归测试保留。当前正式版的普通 DLL 不需要重新安装，此次只调整开发及发布流程。

只有新实验确有需要时，才从归档分支建立独立实验分支，按需迁移所需诊断，不恢复正式版的自动诊断构建与发布。历史标签保留原样，归档不是新的正式版本。
