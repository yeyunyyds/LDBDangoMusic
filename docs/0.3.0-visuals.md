# 0.3.0 视觉与同步

用户已实测确认 0.2.0 demo 显示、真实 LX API 显示成功，同时报告约 500ms 延迟。
本版使用默认 offsetMs=500 提前补偿，不宣称已测得延迟的具体来源。
补偿统一应用于选句和逐字时间。旧配置显式 offsetMs=0 仍被尊重，须手动改为 500 或使用安装脚本。
后台状态轮询从 500ms 改为 150ms，减少暂停/跳转的观察延迟；精度仍受播放器时间信息影响。

## 视觉

- 暖白正文、浅蓝翻译/光晕，均可通过 #RRGGBB 修改。
- 深色四方向描边和轻量四方向柔光；这是偏移纹理叠加，不是高斯模糊。
- 逐字 140ms 平滑淡入、轻微放大与上浮，避免突然切出。
- 换句旧行在 380ms 内淡出、上浮；按歌曲时间计算，暂停时冻结。
- 过渡从当前歌曲时间轴计算，不保留旧歌曲的文字；断连时也不继续绘制旧歌词。
- 精确 LX 单词持续时间细分到字符；word 模式保持原单词时间。
- 普通 LRC 估算逐字/逐词节奏，不冒充真实演唱时间。
- 常用组合附加符、emoji ZWJ、旗帜保为一个显示单位；未实现完整 Unicode UAX #29。
- 限宽、缩小翻译、左右留白；歌词仍是单行缩放，不支持自动多行排版。

## 配置

| 键 | 默认 | 说明 |
|---|---|---|
| offsetMs | 500 | 正值提前，负值延后；demo 不应用播放器补偿 |
| displayMode | character | character / word / line |
| outline | true | 深色描边 |
| glow | true | 轻量光晕；关掉可减少 draw call |
| glowStrength | 0.18 | 0～0.5 |
| transitionMs | 380 | 0～1000，0 立即换句 |
| maxWidth | 0.44 | 行宽上限占屏幕比例，0.2～0.9 |
| opacity | 1 | 0.1～1 |
| textColor | #F4EAFF | 正文 RGB |
| accentColor | #B9DFFF | 翻译/柔光 RGB |

旧文件不包含的新键会使用默认值。修改配置后完整重启游戏和 Host。

## 验证边界

核心回归增加补偿方向、动画边界、过渡时间、Unicode 单位、LX 字符细分与 LRC 估算。
继续运行 Present 路由、歌词解析、播放时钟及模拟 HTTP 集成测试，并交叉编译 x64 Windows DLL/验证程序。
0.3.0 的光晕、动画、实际同步和性能尚待用户 Windows 游戏内验收；0.2.0 实测不能替代新版验收。
