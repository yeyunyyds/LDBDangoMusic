# 0.7.2 高度、远近与可见动画

## 位置菜单

L4N → L4D2DangoMusic 0.7.2 → 位置与数量：

- 歌名：独立高度、左右、距离、大小。
- 作者：独立高度、左右、距离、大小。
- 歌词位置与数量 → **全部歌词高度** / **全部歌词远近**：相对调整全部1～9号位置，保留各位置之间原有差异。未启用的编号也一起调整，日后增加数量时继续使用。
- 各编号歌词仍可单独调节；全部歌词各轴、各组件、全部组件都可重置。

高度从屏幕顶部向下计算，数值越小越高；默认歌词1/2从56%移到44%（中心稍上方）。新增编号以两列向下排列。
歌名和作者保持原有上方默认位置（14%/21%）及420距离，歌词默认距离200；距离越大自然越小，也可以独立补偿大小。
修改实时显示，保存入口在各级页面均可使用。

## 动画

原代码直接按歌曲进度决定弹出阶段；500ms提前量或API/首次显示延迟会让160ms的弹跳在文字真正上屏前就结束。
新代码仍用歌曲时间决定哪些字可以出现，但从字首次进入绘制时记录视觉起点，使用单调时钟运行弹出、上跳与回落，不改变歌曲进度和歌词字词顺序。
抖动使用独立时钟；位置偏移改按屏幕分辨率缩放，避免世界距离较远时被缩到几乎不可见。相机/位置更新不会反复重播同一实例的弹跳。

“动画与停留”新增：

- **恢复默认动画（抖动＋弹跳）**：启用两者，恢复速度/抖动参数。轻柔/简洁预设原本会关闭动画，仍保留这些预设的静态意图。
- **动画预览（示例歌词）**：固定示例内容并循环播放动画，便于不依赖LX播放状态验证。

位置页各级也有“动画预览：开/关”。初次默认静态，开后每4秒循环一轮；关闭恢复静态调位。歌名和作者在预览中保持静态，动画应用于歌词。保存并结束预览后恢复当前播放歌词。

## 默认值迁移

新的 `reanchorMs` 默认0，长句不再自动回到视野。菜单仍可选择3/5/10秒，并显示当前状态。
配置新增 `defaultsVersion=2`：

- 无此标记的旧配置：仅把匹配旧默认56%及后续行默认高度的位置更新为新默认44%及后续行高度；其他自定义高度保留。
- 原3秒默认回屏改为关闭，5/10秒等非默认值保留。希望继续3秒回屏，可在升级后重新选择并保存。
- 配置带标记后，用户明确选择的56%或3秒会保留，不重复迁移。
- 颜色、歌词数量、左右、距离、大小和同步偏移保留。

安装脚本不会提前给旧配置打新版标记；首次运行迁移后，点击保存即可把新值写回配置。
