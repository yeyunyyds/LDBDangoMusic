# 实体歌词持续跟随版

本分支 `experiment/entity-follow-v094` 直接从正式版 v0.9.4（`54ed404`）建立，只迁入实体采集与歌词跟随功能。原角色台词实验保持暂停；本版本没有台词工作线程、字幕消息钩子或字幕字典读取。

## 安装与使用

退出游戏，替换唯一一份 `bin/neko/plugins/L4D2DangoMusic.dll`，保留原 config.json，重新启动。包内只有 README 和 bin。

进入“更多设置 → 实体持续跟随歌词”，等待约半秒，对准目标，选择“锁定准星附近物体（并开启）”。默认显示当前歌曲歌词。关闭菜单后，仍持续跟随锁定实体，转动准星不会换目标。固定示例可用于无音乐环境；局部位置偏移可调节 X/Y/Z。

目标筛选包括玩家、普通/特殊感染者、投掷物、地上武器/物品、动态/物理物体及网络车辆。分类支持不等于所有模型均可挂载；是否成功还取决于实体姿态和父级字段是否可验证。原实验已实机验证部分玩家模型、武器和物品。

## 行为

- 跟随默认关闭，内容默认当前歌词。目标及开关只在当前会话有效，不写进正式配置。
- 位置预览优先于实体跟随；实体跟随优先于场景挂画和普通歌词。关闭跟随恢复原来的显示方式。
- 歌词颜色、翻译、渐显与停留仍使用正式版设置。暂停、停止或 API 断开时当前歌词按原规则隐藏；固定示例不要求 API。
- 目标及最多 16 层父链约 33ms 更新一次；浏览候选约 200ms 更新。使用完整句柄和地图 epoch，失效、休眠、快照过期或切图时隐藏，不自动跳到其他实体。
- 网络姿态可能与游戏插值画面略有偏差；没有精确骨骼/手部附件、静态地图道具枚举和动态遮挡。
- “实验：实体接口只读诊断”可选导出；日志与 entities.jsonl 同在插件数据目录。默认不持续写实体 JSONL。

## 基线与验证

正式版 v0.9.4 的位置复用修正、居中菜单、墙面复用、文字布局、地面放置及默认关闭的挂画背景均保留。实体跟随离线测试覆盖移动/旋转、父子关系、删除和句柄复用、地图变化、过期和休眠、拾取后隐藏等情况。Windows x86 构建和游戏内运行验收分开记录，不把交叉编译当成游戏实测。
