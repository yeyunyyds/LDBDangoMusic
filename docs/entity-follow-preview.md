# 实体歌词持续跟随版

本分支 `experiment/entity-follow-v094` 直接从正式版 v0.9.4（`54ed404`）建立，只迁入实体采集与歌词跟随功能。原角色台词实验保持暂停；本版本没有台词工作线程、字幕消息钩子或字幕字典读取。

## 安装与使用

退出游戏，替换唯一一份 `bin/neko/plugins/L4D2DangoMusic.dll`，保留原 config.json，重新启动。包内只有 README 和 bin。

进入“更多设置 → 实体持续跟随歌词”，等待约半秒，对准目标，选择“锁定准星附近物体（并开启）”。默认显示当前歌曲歌词。关闭菜单后，仍持续跟随锁定实体，转动准星不会换目标。固定示例可用于无音乐环境；局部位置偏移可调节 X/Y/Z。

目标筛选包括玩家、普通/特殊感染者、投掷物、地上武器/物品、动态/物理物体及网络车辆。分类支持不等于所有模型均可挂载；是否成功还取决于实体姿态和父级字段是否可验证。原实验已实机验证部分玩家模型、武器和物品。

## 行为

- 跟随默认关闭，内容默认当前歌词。目标及开关只在当前会话有效，不写进正式配置。
- 位置预览优先于实体跟随；实体跟随优先于场景挂画和普通歌词。关闭跟随恢复原来的显示方式。
- 歌词颜色、翻译、渐显与停留仍使用正式版设置。暂停、停止或 API 断开时当前歌词按原规则隐藏；固定示例不要求 API。
- 目标及最多 16 层父链约 33ms 更新一次；浏览候选约 200ms 更新。使用完整句柄和地图 epoch，失效、休眠、快照过期或切图时隐藏，不自动跳到其他实体。
- 网络姿态可能与游戏插值画面略有偏差；没有精确骨骼/手部附件、静态地图道具枚举和动态遮挡。
- “实验：实体接口只读诊断”可选导出；日志与 entities.jsonl 同在插件数据目录。默认不持续写实体 JSONL。

## 基线与验证

正式版 v0.9.4 的位置复用修正、居中菜单、墙面复用、文字布局、地面放置及默认关闭的挂画背景均保留。实体跟随离线测试覆盖移动/旋转、父子关系、删除和句柄复用、地图变化、过期和休眠、拾取后隐藏等情况。Windows x86 构建和游戏内运行验收分开记录，不把交叉编译当成游戏实测。

## 拿起与丢出恢复修正

可搬物（Gnome、汽油桶、可乐瓶、氧气瓶、煤气罐和烟花盒）被拿起时保留原目标，只隐藏歌词。丢出后可能继续保留拥有者/投掷者字段；新版额外读取该拥有者的当前武器，结合物品已无父级、具有有效独立世界坐标的条件，恢复同一句柄的跟随。再次拿起时自动隐藏。枪械仍沿用原有拾取保护。

仅采集目标、父链和必要拥有者，最多读取 32 个条目，不会为此每帧扫描整个地图。新日志帧标记 diagnostic_build=8。身份仍使用完整句柄；如果游戏销毁后重建了物品，本轮不会仅凭附近有同模型就自动跳到另一件物品，可通过导出快照判断是否属于这种情况。

## Gnome 表示切换补充（诊断 build 9）

在同一句柄恢复以外，新增物理道具与 CGnome 武器实体之间的转接。通过网络属性 m_isCarryable、物理模型编号、武器世界模型编号、当前持有者及其 active weapon 建立关联；不依赖模型名接口可用。

初始物理道具消失、休眠或隐藏后，只接管此前不存在、世界模型编号相同、有唯一有效持有者且在最后位置附近的 CGnome。手持实体结束后，只接管附近新出现的同模型可搬物，或原来那份完整道具句柄。已有同模型物品不参加丢出转接；候选不唯一时等待，不按最近距离二选一。每次转接搜索最多五秒、每 200ms 一次；正常及手持期间仍只更新必要实体。物理道具的 EF_NODRAW 状态会阻止在旧位置继续绘制。

这是有约束的关联识别，不是引擎提供的永久物品 ID；物品在采样间隔内瞬间拿起并丢出、缺少属性、多个候选无法区分或关系不可验证时会隐藏。菜单切换目标及地图变化会清空关联。

entities.jsonl 新增 world_model_index、is_carryable、effects、requested_follow_handle、followed_handle 和 follow_route；主日志会在转接状态变化时记录 Gnome route。反馈时可以看出原来选中的句柄和实际跟随句柄是否发生切换。此前台词实验仍不包含在本分支。
