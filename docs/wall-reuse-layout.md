# 挂画复用、文字布局与地面放置

测试分支：`feature/wall-reuse-layout`。基于 v0.9.3 与位置复用修正，包含菜单默认垂直居中，不包含已归档的实体跟随实验。本轮不升级版本、不发布正式 Release。

## 找不到新表面时复用

“场景挂画歌词 → 无新表面时复用旧挂画”，配置 `wallReuse`，默认 false。

自动放置先按既有五个方向尝试新位置（约 200ms 一个方向）。整轮失败后，在无表面回退的一秒期限前尝试已有挂画，按创建顺序从最早仍保留的一幅开始，之后依次轮换。复用保留原平面的位置、朝向和 ID，只将内容换成当前句，并重新开始本句的生命周期，不会重播历史歌词。

仅复用当前视野内、可见性检查新鲜、未被遮挡且位于搜索距离内的同类表面。没有合适旧挂画时，继续原有无表面回退规则。已选择悬浮回退的句子不会再跳回旧挂画。已淡出并删除的自动挂画不会重新出现；其他旧句按原停留与淡出处理。手动模式沿用原有手动挂画轮换，不依赖本开关。

## 挂画文字布局

入口：“场景挂画歌词 → 挂画外观与维护 → 挂画文字位置与大小（固定预览）”。

歌名、作者、歌词（原文与翻译作为一组）分别设置左右、高度、大小、离表面距离，提供单组件和全部重置。坐标相对于挂画矩形，左右/高度为 0–100%，高度从上边缘计算；大小为 0.25–3 倍，离表面距离为 0.05–16 个游戏单位。此距离是文字离开墙/地面的偏移，不是整幅挂画到相机的距离。

进入编辑时暂停显示真实歌词，提供固定歌名、作者、原文和翻译，不要求音乐 API 或已放置挂画；预览正对视角以便比较布局。实际放置后仍沿选择的墙面/地面朝向。编辑不改变悬浮歌词的独立位置设置。通过“保存设置并结束预览”或原主菜单保存；退出或关闭菜单结束预览。

配置 `wallLayout` 包含 `title`、`artist`、`lyrics`，各有 `x`、`y`、`size`、`depth`。默认布局保留原先歌名、作者和歌词的位置与尺寸。偏移或放大过多可以超出挂画矩形，实际表面支撑/遮挡仍采用现有有限采样，不代表逐字精确遮挡。

## 地面与旋转

在“挂画外观与维护 → 放置表面”选择墙面或地面，配置 `wallSurface` 为 0/1，默认墙面。切换表面会清空旧放置状态，避免混用。

地面模式支持自动向前下方寻找，以及 F8 / 菜单倒计时准星手动放置。只接受朝上的地面及较缓斜坡，拒绝天花板；沿表面固定文字平面，并在放置时确定朝向。仍检查表面支撑、可见性和间距。

“地面文字随视角转向”对应 `wallFloorFollow`，默认 false，旧配置缺失时也关闭。开启后，原文、翻译、歌名、作者共用的文字布局随相机在地面内转向，落点、表面法线与背景保持固定；墙面不受影响。正向下看时使用相机上方向投影作为稳定朝向。关闭恢复放置时固定朝向。

旋转仅作用于文字绘制，不会重新放置挂画或无限扩大搜索范围。挂画背景仍默认关闭。菜单外观重置、悬浮歌名/作者回退、靠近后退规则不在此次调整范围。

## 验证

回归覆盖默认关闭与配置保存、按创建顺序复用/循环、无效可见性/超距/遮挡过滤、回退后禁止迟到复用、五方向搜索失败后及时复用、地面自动搜索与平面几何、相机转向时固定落点，以及布局坐标、边界和默认外观兼容。原生菜单键盘/D3D9 冒烟测试加入保存这些设置与固定预览的路径。云端可执行可移植回归和内存检查，Windows 程序交叉编译；真实游戏画面待实机验收。
