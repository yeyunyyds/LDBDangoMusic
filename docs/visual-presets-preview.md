# 0.9.8-preview1 视觉预览

基于 v0.9.7。新增效果默认关闭，保留原有六套配色、四套渐变配色和全部原有自定义项。一起听、发现、自动搜索和进度应用仍默认关闭；正式构建不含诊断测试。此分支提供视觉测试包，尚需游戏内验收。

## 七套新预设

入口：歌词颜色 → 七套视觉预设与自定义收藏。

| 预设 | 主要效果 |
| --- | --- |
| 极简字幕 | 白字、细描边、减少柔光，柔和退场 |
| 霓虹夜行 | 青紫渐变、当前词提亮、动态柔光与轻微弹跳 |
| 落日胶片 | 米白橙红、暖色翻译、柔和渐入和上浮淡出 |
| 冰晶 | 冰蓝正文、冷白高光、小幅弹跳、缩小退场 |
| 水墨 | 暖灰与米白、柔和渐入、逐字散去 |
| 呼吸悬浮 | 慢速双色呼吸与整句上下浮动 |
| 美术馆 | 更宽的行长、较小的翻译及歌名作者、疏朗间距、简单淡出 |

每套都可选择整套、仅颜色与柔光、仅动画与退场、仅字号与排版。整套包括背景外观，但不会开启挂画，不会移动锚点；仅颜色不会改变动画或字号，仅动画不会改变颜色或位置。音乐来源、API、同步偏移、联机权限、实体跟随规则及位置均不属于视觉预设。

## 原文、翻译及逐字效果

入口：显示与歌词信息 → 原文与翻译样式，或歌词颜色内的同名入口。

- 原文：字号、透明度、行宽；歌名作者另有外观缩放，不改变已配置的位置。
- 翻译：大小、透明度、间距；可沿用原文配色，或独立选择预设颜色和完整 RGB。
- 逐字明暗：未唱、当前、已唱分层，可调未唱/已唱亮度和当前词高光颜色。
- 动态柔光：根据当前词状态调节已有光晕透明度；复用字形纹理，不逐帧重建模糊纹理。需要开启柔光才可见。
- 挂画柔光与描边独立可选，默认关闭；启用后使用透视表面上的缓存纹理绘制。

分层按真实逐字时间轴及词持续时间工作。无逐字时间轴不伪造精确当前词；仍遵循原有“整句显示／估算渐显”选择。若希望同时看见未唱和已唱状态，可关闭“有逐字时间时按时间显字”，整句保留后按真实时间明暗变化。翻译的时间映射来自原文，不声称是独立翻译时间轴。

原文与翻译始终使用同一句的退场状态，透明度和大小只是独立外观，不会导致翻译提前清除。翻译显示总开关保留；预览会固定显示翻译以便调节。

## 退场、浮动与尺寸平滑

动画、速度与停留 → 停留与退场：可选原有、柔和淡出、轻盈上浮、缩小淡出、逐字散去，并设置距离尺寸平滑与耗时。

整句悬浮与入场幅度：可调悬浮开关、周期、幅度、弹跳强度、柔和渐入。柔和渐入是可见时刻的视觉过渡，不改变真实歌词时钟。浮动是额外的外观效果，与已有实体跟随中的上下往复独立。

世界、屏幕和实体歌词使用平滑后的实际字高，歌名作者也可平滑缩放。挂画保留真实表面透视，不延迟或扭曲墙面投影。地图、会话及目标有效性仍由原有逻辑控制。

新退场只改变现有退场期间的外观，不延长旧句寿命，不覆盖停留耗时，不恢复已删歌词。实体实际命中时继续单句替换、禁止叠加旧句；回退世界或挂画后使用各自自然退场。

## 八个自定义槽位

进入“我的预设”，选择槽位，再保存当前外观。可整套或分项恢复，也可清空。操作先记录到内存，返回主菜单“保存设置”后写入配置并跨游戏保留；主菜单仍提示未保存状态。

槽位只保存受限的视觉字段，不保存联机权限、播放控制或场景位置。源文件见 presets/visual-*.json；配置中的 visualStyle 是当前外观，visualPresets 是八个槽位。

## 预览与安装

各页面可进入预览，显示带逐字时间的原文与翻译，循环展示入场、明暗和退场。退出预览恢复当前歌曲，不控制播放器。位置固定预览保留可见编号文字。

下载 L4D2DangoMusic-0.9.8-preview1-visual-preview.zip。退出游戏，仅替换 bin/neko/plugins/L4D2DangoMusic.dll，保留 config.json，避免加载重复 DLL。包内只有 bin 与 README，无新增运行时依赖。预设槽位需保存配置，建议测试前备份配置。
