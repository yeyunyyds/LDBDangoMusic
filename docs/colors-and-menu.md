# 菜单状态与彩色视觉

## 分类一键开关

自动追踪总页和各分类第一页均显示“一键开关：[开启／部分开启／关闭]”。叶子规则全部关闭时，按一下全开；已有部分或全部开启时，按一下全关。分类操作只影响对应分类，总页操作影响全部已列类型。

分类状态按所选类型计算。自动追踪总开关仍可暂停运行并保留类型选择；因此总开关关闭时，分类也可能显示部分开启。保存设置后保留选择。

菜单具体开关开启为绿色，关闭为红色；汇总的部分开启为黄色。进入子菜单的入口为白色，即使入口标签同时显示开关状态，也仍按导航显示白色。数字调整、预设选择、保存等普通操作保持中性颜色。颜色之外始终保留文字说明。

## 可选彩色效果

入口：“歌词颜色 → 彩色、混色与渐变”。原有六套预设、自定义正文与光晕颜色均保留，旧配置默认纯色，不自动启用新效果。

| 模式 | 效果 |
| --- | --- |
| 纯色 | 原来的正文颜色 |
| 双色渐变 | 按整句字符顺序从正文色过渡到光晕色 |
| 逐字彩虹 | 不同字符呈现柔和彩虹色，随时间流动 |
| 流动渐变 | 两色混合随字符位置和时间缓缓流动 |
| 双色呼吸 | 原文与翻译各自整句在两色之间缓慢变化 |

第二色沿用“光晕颜色”；即使关闭柔光，它仍可作为混色第二色。混色强度范围 0～1，流动速度 0～2，均以 0.1 调整。速度 0 可冻结动态配色。强度 0 退回正文基色；纯色模式始终不混色。

新增配色：

| 预设 | 正文色 | 第二色 | 默认模式 |
| --- | --- | --- | --- |
| 海盐落日 | #FFB7A5 | #8EDBFF | 双色渐变 |
| 极光薄荷 | #A7F3D0 | #C4B5FD | 双色渐变 |
| 樱桃汽水 | #FF8FB3 | #FFD68A | 流动渐变 |
| 霓虹光谱 | #FFFFFF | #B6E3FF | 逐字彩虹 |

新效果用于普通、实体和挂画的实际歌词及翻译，也用于颜色页链接的示例预览。菜单自身使用固定状态色，不随歌词彩虹变化。歌名、作者和诊断标记保留原来的颜色语义。

新效果只改变 RGB，不更改透明度、停留、退场、逐字时间轴、目标选择和位置。选择新预设不重置动画参数；选择原有六套预设会恢复相应纯色外观。手动修改强度或颜色后，预设名显示自定义。主菜单保存后跨游戏保留。
