# 实体歌词跟随指南

自 v0.9.5 起，实体跟随和按类型自动追踪正式提供。插件使用受支持游戏构建的网络实体信息，不包含角色台词采集、字幕字典或字幕消息钩子。

## 手动跟随

进入“更多设置 → 实体持续跟随歌词”，等待约半秒，对准物体或角色，选择“锁定准星附近物体（并开启）”。默认显示当前歌曲歌词，关闭菜单后仍跟随锁定实体；转动准星不会自动换目标。“内容”可切换为固定示例，便于没有音乐时验证。

支持的候选包括玩家/生还者、感染者、投掷物、地上武器/物品、动态/物理物体和网络车辆。是否能挂载还取决于网络姿态和父级信息是否可验证。静态地图车辆、精确骨骼、手部附件和第一人称武器挂点不在本接口范围。

手动跟随默认关闭；目标、局部位置、大小和上下往复设置只在本次会话有效。

## 位置与动画

“位置与大小（固定预览）”分别调节左右、高度、前后偏移与大小，提供粗调、细调、单项重置和全部重置。位置沿实体局部坐标，默认 X=0、Y=0、Z=32，偏移范围 ±512；大小默认 1x，范围 0.25～3x。先锁定并开启跟随，进入该页会显示固定原文/翻译示例，返回或关闭菜单后恢复当前歌曲。

实体字幕只保留当前一句。换句时立即移除旧原文及翻译，不使用普通歌词的额外停留和退场淡散，避免在同一物体上叠句。逐字显字、当前句动画、配色继续生效。

实体移动平滑默认开启，可在位置页或“动画、速度与停留 → 歌词移动与实体平滑”关闭。可选择先快后慢、匀速、先慢后快、缓入缓出和回弹，默认先快后慢、350ms。该平滑开关、曲线和耗时可保存。

“整句上下往复”默认关闭；完整周期默认 0.5 秒，幅度为上下各 1 个游戏单位。周期与幅度均支持 ±0.1 调整、恢复默认，并在固定预览中实时显示。它只移动文字，不改变实体或碰撞。

## 自动追踪与回退

自动追踪默认全关。进入“更多设置 → 自动实体追踪（永久规则）”，按特感、队友角色、物品和其他实体分类选择，也可瞄准识别类型后开启/关闭。检测范围默认 1200 游戏单位，同类多个对象选择最近的有效实体。

总页和每个分类第一页的一键开关都有“开启／部分开启／关闭”状态：全关时点击全开，只要已有部分或全部开启就全关。分类只修改自身类型。总开关可以暂停运行并保留所选类型。保存后类型规则跨游戏生效，不保存上一局的实体句柄。

显示优先级：有效手动实体 → 有效自动实体 → 场景挂画 → 普通世界/屏幕歌词。目标失效时回退，规则继续检测。普通歌词和挂画仍保留自己的停留、淡出。主菜单第 9 项“返回普通歌词”可一键停止手动和自动跟随，保留自动类型选择。

## 拿起与丢出

可搬物被拿起时保留手动锁定；在没有精确手部挂点时隐藏实体字幕，并按显示规则回退。丢出后结合拥有者当前武器、父级和独立世界坐标恢复同一句柄。

Gnome 还支持物理道具与手持 CGnome 表示之间的有限转接，核对模型编号、持有关系、附近新出现的唯一候选。它不靠“最近同模型”无条件替换；关系缺失、候选不唯一或错过拾取阶段时会等待或隐藏。转接搜索最多五秒。

自动追踪 Gnome 的物理道具需要模型名，或本地图已经观察到的 CGnome 世界模型编号；信息不足时不把任意物理道具猜成 Gnome。

## 诊断与限制

实体和父级约每 33ms 更新，候选/自动规则约每 200ms 检测。完整句柄、地图 epoch、快照时效、休眠和父级关系检查避免删除或切图后串到其他对象。位置来自网络属性，可能与插值画面有偏差；角色使用近似头顶高度，不是骨骼位置，也不提供动态遮挡。

“更多设置 → 实体接口只读诊断”可导出快照；正常跟随不需要开启持续诊断。主日志和 `entities.jsonl` 同在 `bin/neko/plugins/L4D2DangoMusic/`。当前诊断标记 `diagnostic_build=10`，包含原始/实际跟随句柄、自动请求、姿态与 Gnome 转接状态。
