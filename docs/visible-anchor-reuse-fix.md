# 位置复用与长句回归冲突修正

分支：`fix/visible-anchor-reuse`，基于 main 的 v0.9.3。此问题在 v0.9.2 中使用相同逻辑；本次不重写旧版本或发布新 Release，不包含已归档的实体挂载实验。

## 问题与修正

用户反馈使用一个歌词位置，同时开启长句回归。换句时的 `LyricAnchorSlots::select()` 会检查视野和复用距离，但每帧的长句回归只检查计时。计时到达后，无论歌词是否仍在视野内，都会把当前歌词及其缓存锚点改为预设位置。这会让位置复用看起来失效。

修正将换句复用和长句回归共享同一个可复用判定：

- 两项同时开启：时间到达后，仍在可复用视野范围内且距离 B < A × 系数的锚点保持原位；不满足条件时回归。A 为该编号配置距离，系数默认 3。
- 距离上限的严格小于、既有视野边界和编号轮换保持原样。
- 关闭位置复用：保留原有按间隔回归；关闭长句回归：不定时重新放置。
- 只有成功生成新锚点才更新缓存和回归计时，投影失败不写入无效位置。
- 暂停、换歌、切图等清理行为保持原样，退场歌词不执行定时回归。

回归先在等价旧计时逻辑下失败，再验证修正通过。覆盖单位置、相机平移、3/9 秒仍保持位置、下一句复用、离开视野、可见但超距、关闭复用/计时以及投影失败。云端不运行真实 L4D2，实际游戏效果仍需验收。

## 菜单默认高度

默认左侧垂直居中，随窗口高度和菜单尺寸计算位置。`hudAppearance.centerY` 默认 true。旧配置未写该字段且 y=14（原默认值）时迁移至居中；自定义 y 保留手动位置，显式 centerY=false 的顶端位置也保留。

在菜单位置页按方向键，会从当前实际高度开始手动移动；“重置到默认位置”恢复左侧垂直居中。通过原有“保存设置”保留下次启动。居中模式切换也计入未保存状态。
