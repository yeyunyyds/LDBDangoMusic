# Bird scene-aware preview (PVE)
Branch-only preview; no release. Existing Visual ABI, hooks, FOV and ownership remain unchanged.

Bird is now an independent world-space planner. It samples nearby team and special infected network records at 5 Hz, prefers the direction of travel and sustained evidence of combat, derives candidate aperture from the render projection, ranks bounded independent radius/height pairs, and keeps a valid target until arrival or obstruction. Current position is scored too; a 12-point improvement and 80-unit minimum displacement apply to ordinary relocation. The camera holds for 2 s after arrival, backs off failed searches up to 3 s and uses the existing critically damped controller. Long-distance cuts require a validated landing and 2 s cooldown (2200 units immediately, 1000 units sustained 2.5 s). No near-distance cut. Existing ground anchors remain fixed; invisible current ground lyrics fall back to dedicated subtitles.

Shared recovery retains reachable targets between probes, failed non-bird plans no longer drift, and actual camera movement checks an additional short lookahead before the mandatory segment check. Optional eye angles, ghost and incapacitated fields are resolved from validated receive schemas; unavailable fields are not guessed. Combat is inferred, not a verified attack event. PVE only; no new hooks. Runtime smoke, thresholds and performance need game testing.
