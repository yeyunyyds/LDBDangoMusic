# 0.7.0 组件位置与固定预览

进入 L4N → L4D2DangoMusic → **位置与数量（固定预览）**。
暂时隐藏实时 LX/离线 demo 歌词，用静态的“歌名 · Song Title”“作者 · Artist”“歌词 1～N”替代。播放器和 API 轮询继续工作，预览不改变歌曲进度，不显示未来歌词。
预览包含全部启用的歌词位置，以及歌名、作者，即使正常播放时关闭了歌曲信息或总显示开关，也能调节。

## 菜单

- 歌词位置与数量：1～9 个位置，默认 2。当前句按时间轴的句子编号依次轮换位置；旧句按原有停留/淡出时间退场。不是同时多播放几句，增加位置数也不会延长旧句寿命。
- 歌名与作者位置：分别调节。
- 每个组件有左右、高度、距离、大小页面。左右和高度按画面比例调整（1%/5%）；距离 ±10/50；大小 ±0.05/0.25 倍。各轴可单独恢复默认。
- 单个组件重置、全部歌词位置重置、全部组件位置重置。重置位置保留当前数量；减少数量也保留暂未启用的编号位置。
- **保存设置并结束预览**：使用 L4N 菜单 callback 提交后台保存，结束固定预览，直接恢复当前播放进度的歌词。保存成功/失败状态可在主菜单查看。
- **结束预览，暂不保存**：恢复实时显示，本次改动仍在当前会话生效，重启后使用上次已保存配置。

各级调节菜单都提供保存/结束入口，不必先回主菜单。预览不使用逐字显字、抖动或退场动画；预览歌词采用与实际歌词相同的逐字排版和换行尺寸。

L4N v2 SDK 没有菜单关闭事件。使用上述菜单入口结束预览最可靠；插件也在呈现时检测 Esc 按下并结束预览。通过其他按键关闭整个 L4N 菜单时，请先点保存或结束，避免固定预览继续显示。重新请求插件主菜单也会恢复实时显示。

## 默认布局与坐标

- 歌词1、2：横向为30%和70%，高度均为56%（屏幕中心略下方），距离200，大小1倍。
- 歌名：横向50%、高度14%，距离420，大小1.5倍。
- 作者：横向50%、高度21%，距离420，大小1.1倍。
- 新增编号按两列向下排列，均可重新调整。

高度值从屏幕顶部向下计算，菜单“向上”会减小此值。世界模式下它们描述歌词刚出现/回到视野时的位置：按实际 Source 投影反算世界锚点，随后保留世界空间视差；屏幕模式直接使用画面比例。世界模式受到相机 FOV、画面裁剪和原有最近距离保护影响。
距离越大文字自然越小，独立大小参数可补偿。已有3秒回屏、1秒额外停留、底图恢复和退场过期逻辑保留。

## 配置兼容

新增 `layout` 对象，包含 `lyricCount`、`title`、`artist`、9项 `lyrics` 数组。每个组件保存 `x`、`y`、`distance`、`size`。
旧配置不含 layout 时自动获得新默认位置；旧 `worldDistance` 会作为歌词距离的初值。原来的 API、同步偏移、颜色、动画和歌曲信息显示开关保留。
保存或安装脚本补全配置后包含 layout。切换视觉预设不会覆盖位置。替换 DLL 即可升级；无需删除旧配置。
