# 0.6.1 当前歌词更新和旧句残留修正

用户截图显示重复的相同句子、当前句缺失或旧句不消失。本版本修正已发现的代码路径，但云端无法复现实际 L4D2 画面。

## 修正

- 移除0.6.0依赖 EndScene/Clear 代次的呈现去重。该推断不能覆盖 StretchRect 等路径，可能阻断后续歌词更新及过期实例清理。
- 每次最外层 Present 都重新选择当前进度和句子；仅保留 Present 递归保护。
- 绘制前把干净 backbuffer 复制到独立 RenderTarget，绘制并呈现后恢复原始底图。不会让下一次 Present 在上一句文字像素上继续叠画。
- 保存/恢复失败会记录具体 HRESULT；保存失败时本次不绘制歌词，仍调用原始 Present；Reset 前释放备份资源。
- 单一“当前句＋上一句”生命周期。旧句的退出时间只设置一次，到期删除，不复活退场实例。
- 默认旧句多停1秒、再淡出400ms保留；重复文本不同时保留两份。
- 播放中的小幅时间回跳（最多300ms）不会重新选择上一句；较大回退、前跳、换歌会重置实例，暂停状态的用户拖动仍正常选择。
- 3秒回屏复用当前实例，不重置当前歌曲进度。
- 默认预设改名“暖白浮光”；文件 presets/warm-white.json。来源/许可说明仍保留。

## 成本与边界

每帧增加一次底图保存和一次恢复，增加 GPU 拷贝与 LDB 转发成本。备份使用同尺寸/格式/采样类型；实际 DXVK/MSAA 支持和帧时间待实测。
此方法不撤销其他后处理自身的历史缓存；如仍有拖影，可通过关闭时域类后处理作对照，区分插件像素残留与后处理残影。
本版没有删除用户要求的停留效果，也不把截图判定为已证实的某一种驱动或材质故障。

## 验证

新增软件回归可稳定重现“场景代次不变却应该显示下一句”，检查每次 Present 的当前文字、呈现后干净底图、失败/异常后的恢复、退休实例不复活及绝对过期。
Windows x86 模拟宿主增加原始 Present 观察回调：在实际 Present 前确认有歌词，返回后检查 backbuffer 不含歌词；连续两次呈现都应显示歌词且不累积。已编译，未在 Windows 执行。
Linux 核心/设置/预设/API/动画/相机测试已执行。真实游戏、MSAA和截图中的重影仍需用户验收。

## 安装与诊断

退出游戏和 Host，替换 bin/neko/plugins/L4D2DangoMusic.dll，保留配置。
旧配置 presetId=0 会自动使用新预设名称，无需重置颜色、动画或时间偏移。
若仍异常，提供新的 L4D2DangoMusic.log；开启 cameraDiagnostics 后，JSONL 会包含 lyric_index、presentations、restore_errors。旧的 sceneSerial 去重统计已移除。
