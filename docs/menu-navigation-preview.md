# 菜单导航 · v0.9.8

v0.9.8 在 v0.9.7 及已验收视觉预览的基础上重新组织原生 HUD 菜单，新增两种恢复默认入口。

## 操作与保存

L4N 中选择 L4D2DangoMusic，按 1 打开面板。数字键选择；0 返回上一层，`/` 或 Esc 关闭。需要分页的列表使用 `-` / `=` 翻页。修改立即生效，操作后留在当前页，不增加菜单层数。开关保持绿/红状态，普通导航为白色；不可用项置灰。菜单项不显示导航箭头。

主菜单“保存设置”固定在第 7 项。配置有变化时显示 `[未保存]`，保存成功才清除。切换预设应用范围、进入预览等临时操作不会写入配置。记录收藏、清空收藏、恢复默认也需要最后保存，才能在重启后保留。

## 一级：主菜单

```text
[1] 歌词显示：[开启/关闭]
[2] 外观与预设 →
[3] 动画与退场 →
[4] 位置与场景 →
[5] 音乐与歌曲信息 →
[6] 实体跟随 →
[7] 保存设置 [未保存]
[8] 系统与恢复 →
[9] 返回普通歌词（仅实体跟随开启时显示）
```

## 二级及以下：外观与预设

```text
外观与预设
├─ 视觉预设：[当前名字/自定义]
│  ├─ 应用范围：[整套/仅颜色/仅动画/仅排版]（每页固定第一项）
│  ├─ 第 1 页：七套新视觉预设
│  ├─ 第 2 页：六套经典预设
│  └─ 第 3 页：四套渐变配色
├─ 我的预设（八个收藏）
│  └─ 收藏 1～8
│     ├─ 应用范围
│     ├─ 应用此收藏（空槽不可用）
│     ├─ 保存当前外观到此槽（覆盖）
│     └─ 清空此槽
├─ 原文样式
│  ├─ 显示大小、透明度、单行长度
│  └─ 正文颜色 → 颜色/RGB 调节
├─ 翻译样式
│  ├─ 显示翻译、大小、透明度、原文与翻译间距
│  ├─ 沿用原文配色
│  └─ 独立颜色 → 颜色/RGB 调节
├─ 配色与柔光
│  ├─ 着色方式、第二色/光晕颜色
│  ├─ 混色强度、流动速度
│  └─ 柔光开关、强度、半径、描边
├─ 逐字明暗
│  ├─ 明暗分层、未唱/已唱亮度、当前词高光颜色
│  ├─ 动态柔光（需先开启基础柔光）
│  └─ 基础柔光设置（快捷入口）
├─ 歌名作者外观缩放
└─ 效果预览
   ├─ 保存设置
   └─ 结束预览并回主菜单
```

点击预设名直接按当前范围应用，不再逐个进入确认菜单。收藏也按同一个应用范围工作。颜色范围不改动画，动画范围不改颜色，排版范围只改字号等外观排版，不改变世界锚点。自定义收藏不包含联机授权、音乐来源、同步偏移、实体规则或组件位置。

数值页统一提供：减小、增大、恢复此项默认值、最小值、最大值。各参数有独立边界和步长。颜色仍保留原有精细调节。逐字明暗需要真实逐字时间；无时间轴的估算渐显在动画菜单单独设置。

## 二级及以下：动画与退场

```text
动画与退场
├─ 显字方式 → 按逐字时间显字 / 无时间轴整句或估算 / 显字速度
├─ 入场效果 → 弹跳开关 / 弹跳幅度 / 柔和渐入
├─ 抖动 → 开关 / 频率 / 幅度
├─ 整句悬浮 → 开关 / 周期 / 幅度
├─ 换句移动 → 开关 / 移动曲线 / 共享移动耗时
├─ 距离字号平滑 → 开关 / 耗时
├─ 停留与退场 → 额外停留 / 退场耗时 / 退场外观
│  └─ 退场外观 → 原有 / 淡出 / 上浮 / 缩小 / 逐字散去
```

换句移动与实体位置平滑共用移动曲线、移动耗时，页面明确标注。各自开关独立。实体歌词保持单句替换；普通世界歌词和挂画仍按其停留/退场规则运行。

```text
│  ├─ 作者位置 → 左右 / 高低 / 距离 / 大小

│  └─ 视野复用 / 复用距离阈值 / 长句回归及秒数 / 靠近后退

   ├─ 挂画开关 / 自动或手动 / 墙面或地面 / 手动放置

   │  └─ 搜索距离 / 间距 / 数量上限 / 复用旧挂画 / 世界歌词回退
```

进入固定预览页面时暂时显示示例内容，离开后恢复歌曲，不控制播放器。数量页与统一调整入口在歌词位置列表每页顶部保留。挂画跟随全局时间时显示实际全局值，独立参数不允许偷偷覆盖；地面随视角旋转仅在地面模式可操作。背景仍默认关闭。

## 二级及以下：实体跟随

```text
实体跟随
├─ 手动锁定与解除
│  └─ 手动开关 / 准星锁定 / 切换候选 / 解除 / 候选过滤 / 状态
├─ 自动追踪
│  ├─ 自动追踪开关 / 一键开关全部类型
│  ├─ 特感 / 队友 / 物品 / 其他（分类可分页）
│  │  ├─ 一键开关本分类：[开启/部分开启/关闭]（每页顶部）
│  │  └─ 各类型单独开关
│  ├─ 准星识别并设置目标类型 → 开启 / 关闭 / 调整范围
│  └─ 搜索范围 → 减小 / 增大 / 默认值
├─ 实体歌词布局 → 左右 / 高低 / 距离 / 大小 / 重置
├─ 跟随运动
│  ├─ 实体位置平滑 / 共享移动曲线 / 共享移动耗时
│  └─ 实体专属上下往复 → 开关 / 周期 / 幅度
└─ 关闭全部实体跟随
```

分类与全部的一键开关遵循：全部关闭时按下全开；部分开启或全部开启时按下全关。解除目标不等于关闭歌词总开关。有效实体优先，无实体时仍按挂画、世界歌词依次回退。

## 二级及以下：系统与恢复

```text
系统与恢复
├─ 菜单外观 → 原有位置、大小、颜色等设置
├─ 恢复默认外观（立即应用，不自动保存）
├─ 恢复全部设置 → 确认页
│  ├─ [1] 确认恢复并返回主菜单
│  └─ [2] 取消（回到系统页）
├─ 一起听（实验，默认关闭）
│  └─ 总开关 / 同局发现 / 自动搜索 / 应用进度 / 声明房主
│     / 玩家列表 / 同步阈值 / 重试 / 状态
└─ 版本与路径
```

确认页说明不占数字键。普通构建不含诊断工具入口；诊断代码已归档至 archive/diagnostics-v0.9.8，主线不再构建或发布诊断包。

| 恢复项 | 恢复默认外观 | 恢复全部设置 |
| --- | --- | --- |
| 颜色、柔光、字号、排版、显字和动画 | 恢复安装默认值 | 恢复安装默认值 |
| 实体专属上下往复 | 恢复默认值 | 恢复默认值 |
| 世界/挂画/实体位置与距离 | 保留 | 恢复默认值 |
| 显示内容开关、音乐来源、API、同步偏移 | 保留 | 恢复默认值 |
| 实体锁定与自动类型规则 | 保留 | 解除并恢复默认值 |
| 一起听及网络权限 | 保留当前设置 | 关闭并清理本插件通道 |
| 菜单外观 | 保留 | 恢复默认值 |
| 八个自定义收藏 | 保留 | 保留 |
| 配置文件 | 不自动覆盖 | 不自动覆盖 |

全部恢复使用随安装包分发的真实默认配置，不使用开发测试用的空 Config 默认值。确认后清除预览与旧歌词显示，等待当前来源重新获取，避免旧请求让历史歌词重新出现。恢复后仍需“保存设置”才能跨次保留。

一起听各项仍默认关闭；关闭总开关不绑定、发现、轮询或收发 P2P。启用后再关闭只清理一次本插件通道。整理菜单没有扩大联机权限。真实多账号联机仍未测试，不保证 VAC 安全，详见项目免责声明。
