L4D2DangoMusic v0.9.4 是适用于《求生之路 2》的纯 L4N 歌词插件，无需 LDB 或 DXVK。

本次更新：

- 修正位置复用与长句回归的冲突：两项同时开启时，仍在视野内且未超出复用距离上限的歌词保持原位；移出视野或超距后才按回归规则重新放置。
- 菜单默认左侧垂直居中。旧默认顶端位置自动迁移，已保存的自定义高度保留；位置页可重置到默认位置。
- 新增挂画复用，默认关闭。找不到新的合适表面时，按创建顺序从最早仍保留的挂画起轮换复用，跳过不可见、遮挡和超距目标；复用显示当前句，不重播历史歌词。
- 新增挂画文字布局页，固定预览歌名、作者、原文及翻译；分别调整左右、高度、大小和离表面距离，支持单组件及全部重置、保存设置。
- 新增地面放置，可自动寻找前下方地面，或用 F8 / 菜单倒计时手动放置。默认仍为墙面。
- 新增地面文字随视角转向，默认关闭。开启后文字布局随视角转向，挂画落点、表面法线与背景保持固定，墙面挂画不受影响。
- 挂画背景继续默认关闭。保留旧挂画自然停留/淡出，以及按句锁定墙面或悬浮回退的行为。

入口：“场景挂画”控制复用，“挂画外观与维护”调整文字布局、选择表面和地面文字转向。“保存设置”仍在主菜单第 7 项。按 1..9 选择、0 返回、Esc 或 / 关闭，- / = 翻页。

安装：

1. 退出游戏，下载 `L4D2DangoMusic-0.9.4-l4n.zip`，预先安装 L4N。
2. 首次安装将压缩包内 bin 合并到游戏根目录。升级时仅替换 `bin/neko/plugins/L4D2DangoMusic.dll`，保留自己的 config.json。
3. 移出旧名称或重复的歌词插件 DLL，完整重启游戏。

安装包仅包含 bin 与 README.md，无额外依赖或游戏资源。新增开关在旧配置未设置时均采用关闭状态，放置表面默认墙面。

已完成可移植回归、内存检查、菜单字库检查及 Windows x86 交叉编译，相关测试版已由用户实机验收。实体挂载和 NPC 台词继续保留在独立实验分支，不包含在本 Release 中。
