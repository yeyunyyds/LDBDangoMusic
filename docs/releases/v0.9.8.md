# L4D2DangoMusic v0.9.8

新增可选视觉效果并整理菜单入口，保留已验收的歌词、场景挂画、实体跟随及音乐来源功能。

- 七套新视觉预设、八个自定义外观收藏，支持整套或仅颜色、动画、排版应用；经典配色和渐变配色统一收纳。
- 原文与翻译独立字号、透明度、颜色及间距；可选逐字明暗、动态柔光、整句悬浮、退场样式和距离字号平滑。
- 主菜单固定一页，按外观、动画、位置与场景、音乐、实体、系统归类；菜单项不显示导航箭头，开关保留状态颜色。
- 保存设置固定在第 7 项，修改后显示 [未保存]，操作实时刷新、不叠加菜单层数。
- 新增恢复默认外观、恢复全部设置。收藏均保留；全部恢复需确认，会关闭联机、解除实体锁定并清理旧歌词。恢复后需手动保存。

## 下载与升级

普通用户下载 **L4D2DangoMusic-0.9.8-l4n.zip**。诊断工具单独提供为 **diagnostics.zip**，不要同时加载两份 DLL。

退出游戏后只替换 bin/neko/plugins/L4D2DangoMusic.dll，保留自己的 config.json。首次安装先安装 L4N，再将 bin 合并到游戏根目录。包内仅 bin 与 README，无需 .NET 或额外 Steam DLL。

一起听、同局发现、自动搜索和进度应用默认关闭；关闭总开关时不绑定、探测或轮询 P2P。挂画背景默认关闭。
