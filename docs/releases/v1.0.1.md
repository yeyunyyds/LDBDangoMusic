# L4D2DangoMusic v1.0.1

本版本正式引入 AFK 自动运镜与场景化歌词联动，新增 Folia 原生音乐接口支持，让歌词从独立的视觉效果进一步融入游戏场景。同时重构鸟瞰追踪，改善多人合作战役中镜头的观察方向、狭窄空间适配和连续性。原定 v1.0.0 的全部功能介绍一并纳入本次发布。

## AFK 自动运镜

闲置时自动接管游戏相机，根据人物位置、移动方向与周围建筑环境规划镜头。恢复操作后，默认返回第一人称视角。

提供五种运镜风格：

- **鸟瞰追踪（默认）**：优先展示队伍推进方向与交战区域，根据环境调整摄影高度，歌词呈现在附近地面。
- **人物环绕**：围绕人物进行动态运镜，搭配人物侧面的悬浮歌词。
- **建筑歌词**：利用建筑结构进行远距离构图，将歌词融入建筑场景。
- **场景远景**：扩大观察范围，呈现人物与地图环境。
- **墙面运镜**：寻找合适的墙面，结合固定歌词进行运镜。

支持混合运镜，可自由选择参与自动切换的镜头类型。

## 鸟瞰追踪重构（v1.0.1）

- 优先展示队伍推进方向与正在发生的交战，而不是持续拍摄人物正面。根据附近求生者与可见特感的网络状态、移动、瞄准及伤害等迹象推断交战方向。
- 独立选择镜头高度与水平距离。低天花板、狭窄房间和走廊允许使用较低角度的斜视构图。
- 根据视野覆盖、遮挡、空间余量、移动方向与镜头连续性选择摄影位置。现有构图有效时优先原地观察，避免短距离反复定位。
- 交战目标切换与注视点变化采用平滑过渡；移动目标保持稳定，抵达后短暂驻留，失败后降低搜索频率。
- 远距追赶困难时允许安全切镜，近距离遮挡优先等待或平滑调整。镜头恢复不受远处特感单独驱动。

## 场景化歌词

- 鸟瞰歌词自动寻找人物周围适合放置文字的地面。
- 鸟瞰歌词固定于场景世界坐标，不随人物或相机移动。
- 根据建筑遮挡、地面支撑与镜头视野选择歌词布局。
- 无合适放置位置时使用屏幕字幕；持续不可见时，本句单向降级为屏幕字幕，避免同一句歌词在不同显示模式间反复切换。

## 运镜稳定性与测试

- 各运镜共享恢复目标锁定、碰撞预检与减速机制，减少反复重定位。
- 新增场景决策日志及鸟瞰回归测试，包括低天花板、队友与特感筛选、视锥、目标锁定、远距离恢复及 Windows SDK 兼容检查。

## Folia 音乐支持

新增 Folia Stage API 原生接入，无需额外的音乐桥接程序。保留 LX、网易云音乐等现有音乐来源。

## 菜单与设置

- 主菜单第 6 项新增「AFK 自动运镜」独立入口，第 7 项为实体跟随，第 8 项保存设置。
- 支持自定义闲置等待时间、运镜风格及接管后的视角行为。
- AFK 运镜默认关闭，新配置默认风格为鸟瞰追踪。已有配置的明确保存值保持不变。
- 关闭 AFK 运镜时，不执行其镜头规划、人物追踪与歌词地面搜索。

## 安装与兼容性

普通歌词功能仍可独立使用，无需 LDB 或 DXVK。

AFK 自动运镜需要支持 FreeCamera ABI v4 的 [L4D2Visual](https://github.com/yeyunyyds/L4D2-Visual-Effects)，并开启外部相机控制授权。配套使用 [Visual v1.1.0](https://github.com/yeyunyyds/L4D2-Visual-Effects/releases/tag/v1.1.0)。旧版 Visual v1.0.0 不含该接口。

本版同时适配 2026 年 11 月更新后的游戏模块，保留未知游戏版本的安全检查。

下载 `L4D2DangoMusic-1.0.1-l4n.zip`。升级用户请退出游戏后仅替换 `bin/neko/plugins/L4D2DangoMusic.dll`，保留原有 `config.json`。首次安装需先安装 L4N，再将安装包中的 bin 合并到游戏目录。仅加载一份插件。

## 验证与风险

自动回归测试、Windows x86 正式版编译和安装包构建已通过。

鸟瞰策略针对 PVE 合作战役设计，交战状态依赖可用的客户端网络数据推断，不保证所有模型、房间及服务器环境的识别效果。自动化回归与 Windows x86 构建不等于实机验收。联机一起听默认关闭，未充分验证真实多账号联机，**不保证 VAC 安全**。
