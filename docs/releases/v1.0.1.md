# L4D2DangoMusic v1.0.1

本版本包含 v1.0.0 的 AFK 自动运镜、场景化歌词及 Folia Stage API 支持，并重点重构鸟瞰追踪，改善多人合作战役中镜头的观察方向、狭窄空间适配和连续性。

## 鸟瞰追踪

- 优先展示队伍推进方向与正在发生的交战，而不是持续拍摄人物正面。根据附近求生者与可见特感的网络状态、移动、瞄准及伤害等迹象推断交战方向。
- 独立选择镜头高度与水平距离。低天花板、狭窄房间和走廊允许使用较低角度的斜视构图。
- 根据视野覆盖、遮挡、空间余量、移动方向与镜头连续性选择摄影位置。现有构图有效时优先原地观察，避免短距离反复定位。
- 交战目标切换与注视点变化采用平滑过渡；移动目标保持稳定，抵达后短暂驻留，失败后降低搜索频率。
- 远距追赶困难时允许安全切镜，近距离遮挡优先等待或平滑调整。镜头恢复不受远处特感单独驱动。

## 运镜稳定性与歌词

- 各运镜共享恢复目标锁定、碰撞预检与减速机制，减少反复重定位。
- 鸟瞰地面歌词按句固定世界位置，不随人物移动。持续不可见时本句单向降级为屏幕字幕，避免反复切换。
- 新增场景决策日志及鸟瞰回归测试，包括低天花板、队友与特感筛选、视锥、目标锁定、远距离恢复及 Windows SDK 兼容检查。

## 安装与使用

普通歌词无需 LDB 或 DXVK。AFK 运镜需要兼容 FreeCamera ABI v4 的 [L4D2Visual](https://github.com/yeyunyyds/L4D2-Visual-Effects)，并在 Visual 中主动开启外部接口授权。AFK 默认关闭，新配置默认鸟瞰追踪。主菜单第 6 项为 AFK 自动运镜，第 7 项为实体跟随，第 8 项保存设置。恢复操作默认返回第一人称。

本版保留 LX、网易云及 Folia Stage API 原生支持，无需额外桥接 EXE。

下载 `L4D2DangoMusic-1.0.1-l4n.zip`。退出游戏后升级仅替换 `bin/neko/plugins/L4D2DangoMusic.dll`，保留原配置；首次安装先安装 L4N，将 bin 合并至游戏根目录。仅加载一份插件。

## 验证与风险

鸟瞰策略针对 PVE 合作战役设计，交战状态依赖可用的客户端网络数据推断，不保证所有模型、房间及服务器环境的识别效果。自动化回归与 Windows x86 构建不等于实机验收。联机一起听默认关闭，未充分验证真实多账号联机，**不保证 VAC 安全**。
