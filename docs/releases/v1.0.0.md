# L4D2DangoMusic v1.0.0

本版本正式引入 AFK 自动运镜与场景化歌词联动，新增 Folia 原生音乐接口支持，让歌词从独立的视觉效果进一步融入游戏场景。

## AFK 自动运镜

闲置时自动接管游戏相机，根据人物位置、移动方向与周围建筑环境规划镜头。恢复操作后，默认返回第一人称视角。

提供五种运镜风格：

- **鸟瞰追踪（默认）**：从高处观察人物与周围环境，歌词呈现在附近地面。
- **人物环绕**：围绕人物进行动态运镜，搭配人物侧面的悬浮歌词。
- **建筑歌词**：利用建筑结构进行远距离构图，将歌词融入建筑场景。
- **场景远景**：扩大观察范围，呈现人物与地图环境。
- **墙面运镜**：寻找合适的墙面，结合固定歌词进行运镜。

支持混合运镜，可自由选择参与自动切换的镜头类型。

## 场景化歌词

- 鸟瞰歌词自动寻找人物周围适合放置文字的地面。
- 鸟瞰歌词固定于场景世界坐标，不随人物或相机移动。
- 根据建筑遮挡、地面支撑与镜头视野选择歌词布局。
- 无合适放置位置时使用屏幕字幕，避免同一句歌词在不同显示模式间反复切换。

## Folia 音乐支持

新增 Folia Stage API 原生接入，无需额外的音乐桥接程序。保留 LX、网易云音乐等现有音乐来源。

## 菜单与设置

- 主菜单第 6 项新增「AFK 自动运镜」独立入口，第 7 项为实体跟随，第 8 项保存设置。
- 支持自定义闲置等待时间、运镜风格及接管后的视角行为。
- AFK 运镜默认关闭，新配置默认风格为鸟瞰追踪。已有配置的明确保存值保持不变。
- 关闭 AFK 运镜时，不执行其镜头规划、人物追踪与歌词地面搜索。

## 安装与兼容性

普通歌词功能仍可独立使用，无需 LDB 或 DXVK。

AFK 自动运镜需要支持 FreeCamera ABI v4 的 [L4D2Visual](https://github.com/yeyunyyds/L4D2-Visual-Effects)，并开启外部相机控制授权。配套使用 [Visual v1.1.0](https://github.com/yeyunyyds/L4D2-Visual-Effects/releases/tag/v1.1.0)。旧版 Visual v1.0.0 不含该接口。

本版同时适配 2026 年 11 月更新后的游戏模块，保留未知游戏版本的安全检查。

升级用户请退出游戏后替换插件 DLL，保留原有 `config.json`。首次安装需先安装 L4N，再将安装包中的 bin 合并到游戏目录。

自动回归测试、Windows x86 正式版编译和安装包构建已通过；实际游戏体验与联机兼容性仍需验证。

**联机功能未经充分验证，不保证 VAC 安全。**
