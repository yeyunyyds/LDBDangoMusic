L4D2DangoMusic v0.9.2 是适用于《求生之路 2》的纯 L4N 歌词插件，无需 LDB。

本次更新：

- 修正悬浮世界歌词的“靠近时后退”，歌名与作者也支持后退；固定挂画保持贴墙。
- 修正无逐字时间轴时的估算渐显，改善短句、无空格词和时间偏移情况下的表现；翻译同步渐显。
- 上一句翻译现在跟随原句停留、上浮和淡出，避免换句时立即消失。
- “长句回到视野”新增自定义间隔，支持 0.1～300 秒，保留关闭和 3/5/10 秒预设。
- 可配置视野内旧位置的复用距离，默认仅复用距相机小于组件配置距离 3 倍的位置。

安装：

1. 退出游戏，下载 `L4D2DangoMusic-0.9.2-l4n.zip`。
2. 将压缩包中的 `bin` 合并到游戏根目录，需要预先安装 L4N。
3. 已有用户可仅替换 `bin/neko/plugins/L4D2DangoMusic.dll`，保留原配置，并清理旧名称的重复插件 DLL。
4. 启动游戏，通过 L4N 的 L4D2DangoMusic 菜单设置；修改后可选择“保存设置”。

安装包仅包含 `bin` 和 `README.md`；源码通过 GitHub 自动提供的源码归档下载。实验性实体挂载不包含在此稳定版本中。
