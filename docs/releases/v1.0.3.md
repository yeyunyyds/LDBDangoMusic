# L4D2DangoMusic v1.0.3

本次更新集中降低 AFK 待机与歌词绘制的性能开销，保留原有运镜风格、歌词样式及配置格式。

## AFK 自动运镜
- 待机管理统一为每秒一次：检查 Visual 授权、会话状态并维持心跳；实际运镜仍按原有帧频更新。
- 缓存经过验证的 FreeCamera ABI，减少重复接口解析；仅在实际接管后采集人物与计算运镜。
- 配置仅在变更或新会话时提交；状态清理仅在必要的切换时执行，减少无授权状态下重复分配。
- 用户输入接管仍由 Visual 高频处理；闲置自动接管可能额外延迟不到一秒。

## 歌词渲染
- 无绘制需求时跳过全屏 BackBuffer 备份和恢复；绘制时复用同一帧已获取的 BackBuffer 及描述。
- 复用 D3D9 StateBlock 与 DeviceCaps，设备重置或销毁时释放相应资源。
- 合并普通和空间歌词的同字符描边与本体绘制，保留发光及原有绘制顺序。
- 缓存墙面及 AFK 空间歌词排版，保持动态投影和动画。
- 字形纹理改为按最近使用时间淘汰，不再超过 256 项即整批重建；默认估算预算 64 MiB、2048 项，帧间淘汰。只在相关字体、发光纹理参数或设备变化时清理缓存。
- 配置快照仅在变更时复制。

## 安装与兼容
完整退出游戏后替换 bin/neko/plugins/L4D2DangoMusic.dll，保留 config.json。首次安装先安装 L4N，再合并安装包内 bin 目录，避免重复加载。
普通歌词不依赖 LDB、DXVK 或 Visual。AFK 需要 FreeCamera ABI v4，建议搭配 L4D2Visual v1.1.2 并开启外部控制授权。AFK 和联机一起听仍默认关闭。

## 验证与限制
正式候选包由 CI 执行回归、Windows x86 编译及安装包校验，整合实机测试后再发布。性能收益取决于场景、分辨率、MOD、驱动与歌词样式，不保证固定 FPS；需关注菜单、Alt-Tab、设备重置与运镜交接。联机一起听未充分验证真实多账号联机，不保证 VAC 安全。
