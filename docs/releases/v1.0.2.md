# L4D2DangoMusic v1.0.2

本次更新集中优化 AFK 鸟瞰追踪，让相机拥有更自然的运动节奏，而不是始终追赶人物。

## 鸟瞰运镜
- 新增连续缓慢跟拍：人物小范围移动时，相机可持续调整位置与观察方向，不受普通构图驻留时间限制。
- 默认跟拍速度 50 游戏单位/秒，加速度 90 单位/秒²。允许人物与镜头的相对距离自然变化，构图明显失衡时才加速追赶；恢复后平滑减速。
- 连续快速追赶的选择概率依次为 100%、50%、25%、12.5%……，也可采用其他移动方式或安全切镜，减少连续快速运镜带来的视觉疲劳。
- 短暂遮挡容忍 1.5 秒，优先寻找附近可达机位；持续遮挡 5 秒或严重失联时允许安全切镜。
- 正在执行的有效移动路径不再被普通构图刷新计时器打断。
- 提高 Tank 交战的构图权重，兼顾求生者与交战对象。
- 最高两档鸟瞰候选高度由 540 / 350 降至 480 / 320。

## 安装与兼容性

本次未改变歌词系统、其他运镜模式或配置格式。AFK 自动运镜仍默认关闭，需要 [L4D2Visual v1.1.0](https://github.com/yeyunyyds/L4D2-Visual-Effects/releases/tag/v1.1.0)（FreeCamera ABI v4）及外部相机授权。普通歌词仍独立运行，不需要 LDB 或 DXVK。

下载 `L4D2DangoMusic-1.0.2-l4n.zip`。升级用户完整退出游戏后替换 `bin/neko/plugins/L4D2DangoMusic.dll`，保留自己的 `config.json`。首次安装请先安装 L4N，再将安装包中的 bin 合并至游戏目录，仅加载一份插件。

此前功能介绍见 [v1.0.1](https://github.com/yeyunyyds/LDBDangoMusic/releases/tag/v1.0.1)。

## 验证与限制

新增慢速限速、加速度、跟拍追赶、遮挡恢复和快速运镜概率回归测试。正式包经过自动回归测试、Windows x86 编译及安装包校验后发布。路径规划仍为短距离分段碰撞检测，而非完整地图寻路；不同地图、人物模型和服务器中的实机效果仍需验证。联机一起听默认关闭，未充分验证真实多账号联机，**不保证 VAC 安全**。
