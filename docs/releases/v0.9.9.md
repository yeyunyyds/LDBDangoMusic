# L4D2DangoMusic v0.9.9

## AFK 自动运镜
- 主菜单独立入口，固定九项；保存设置移至第 8 项，实体跟随解除保留在二级菜单。
- 总开关默认关闭并可保存；新配置默认鸟瞰追踪，混合风格允许勾选五种镜头。已有明确保存值的配置保持不变。
- 连续平滑跟踪、移动方向预测、狭窄场景曲线跟随、丢失目标时受限恢复；接管默认恢复第一人称，可选保留 FreeCamera。
- 鸟瞰歌词按句在八个方向搜索地面支撑、遮挡和可见性；固定世界位置及朝向直到退场。不在句中切换屏幕字幕或重新定位。
- AFK 运镜需要配套 Visual FreeCamera ABI v4 构建（Visual v1.0.0 不含该接口）并授权；普通歌词不需要 Visual。

## 音乐与安装
新增原生 Folia Stage API 来源。退出游戏后替换 DLL，保留旧 config.json；首次安装将 bin 合并到游戏目录。正式 Windows x86 安装包不含诊断功能。普通使用无需额外 EXE。

自动测试、Windows x86 构建和真实游戏实测是不同验证范围；真实联机及 VAC 安全不作保证。
