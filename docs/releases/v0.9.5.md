L4D2DangoMusic v0.9.5 是《求生之路 2》的原生 L4N 歌词插件，不依赖 LDB 或 DXVK。本版本将已验收的实体跟随、自动追踪和视觉更新确立为正式功能；角色台词实验继续独立，不包含在本 Release 中。

本次更新：

- 新增手动实体歌词跟随，可调整局部位置、大小和整句上下往复；实体字幕单句替换，原文与翻译一起更新，避免叠句。
- 新增按类型自动追踪：特感、队友角色、武器/物品及其他网络实体分类分页，范围内有多个目标时选择最近的有效实体。支持瞄准识别、单类型开关、分类和全局一键开关，保存后跨游戏保留规则；默认全部关闭。
- 一键开关提供开启、部分开启、关闭三态：全关时点击全开，部分或全开时点击全关。菜单开启为绿色、关闭为红色、部分开启为黄色，子菜单入口为白色。
- 修正普通歌词编号复用、挂画复用/容量限制和实体设置重置导致的旧句提前消失。实体、世界及挂画退场状态隔离；实际没有有效实体时回退，普通歌词与挂画继续自然停留/淡出。
- 挂画默认沿用全局停留和退场，可显式设置独立时间；退场中的面板不会为新句直接覆盖。暂停、切歌、切图和拖动进度仍立即清理。
- 新增实体平滑，默认开启；新增可选的全局换句移动，默认关闭，支持多个编号位置。提供先快后慢（默认）、匀速、先慢后快、缓入缓出和回弹，默认耗时 350ms。
- 保留原有六套颜色预设、自定义颜色及柔光，新增双色渐变、逐字彩虹、流动渐变和双色呼吸，以及海盐落日、极光薄荷、樱桃汽水、霓虹光谱四套配色。新效果默认关闭，可调整强度和速度并保存。
- 支持可搬物拾取/丢出的恢复及有关系证明的 Gnome 表示转接；完善目标、地图、完整句柄、休眠及快照检查。
- 主菜单第 7 项仍为保存设置；开启跟随后，第 9 项可返回普通歌词。修正该按钮被返回菜单过滤规则误删的问题。

入口：

- 更多设置 → 实体持续跟随歌词 / 自动实体追踪（永久规则）。
- 动画、速度与停留 → 歌词移动与实体平滑。
- 歌词颜色 → 彩色、混色与渐变。

安装与升级：

1. 完整退出游戏，下载 `L4D2DangoMusic-0.9.5-l4n.zip`，先安装并确认 L4N 可用。
2. 首次安装将 bin 合并到游戏根目录；升级仅替换 `bin/neko/plugins/L4D2DangoMusic.dll`，保留自己的 config.json。
3. 移出旧名称和重复的歌词 DLL，只加载一份插件，再重启游戏。

安装包仅包含 bin 与 README.md，无额外依赖、源码、构建工具或游戏资源。自动类型规则、移动及配色设置保存后保留；手动目标、实体局部位置/大小和上下往复仍为会话设置。

实体功能使用受支持构建的网络姿态和近似高度，不提供精确骨骼、手部附件、静态场景物品枚举或动态遮挡。模型信息缺失或候选不唯一时不会猜测挂点。

相关功能已由用户实机验收；发布前完成可移植回归、内存检查、完整菜单字库检查和 Windows x86 构建。
