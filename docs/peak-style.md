# 0.6.0 Peak-inspired 原生歌词

按用户最终要求模仿 PeakDangoMusic 的视觉，不依赖 Unity/TMP，也没有复制 TMP shader、材质或引擎资源。
参考版本 c9fe555b53f7d3cea85bfdcb92476a1ed6853ad0。

## 对齐内容

- 正文 #F7E1D7；翻译默认关闭，开启时为较小的同色文字。
- 全句字符保持排版位置，以播放器的原词时间分组显现；同词内不再均匀切成打字机节奏。
- 对齐 160ms 弹出收回、峰值 1.55；alpha 在约 53ms 达到 1。
- 无词时间时按英文词/CJK 两字分组，估算跨度 min(句长75%, 每组330ms)。
- 8Hz 量化抖动，默认强度 0.8；字符旋转/位置/缩放使用稳定散列。
- 显字用歌曲时钟；抖动和退场用单调时钟，暂停时文字位置的轻微动画仍可运行。
- 入场默认为直接、仅保留字符显现；旧句 400ms 淡出上浮；最多保留四个歌词实例。
- 拖动进度超过 1800ms、换歌、世界/屏幕切换、设备 Reset 时清理实例，避免旧字残留。
- 三行居中布局。屏幕回退按 22%/78% 左右位置、61% 高度；世界歌词按约 30度散布的80%在两侧交替，轻微上仰。
- 靠近世界歌词时退至设置距离的60%，默认继续面向屏幕显示。
- 中日韩空格拆分合并歌词，保留词时间；太短的分句按500ms/两字规则合并。
- 默认关闭相机状态文字与测试标记，debugOverlay/worldTestAnchor 可以单独开启。

## 原生适配差异

世界文字仍采用已验证的世界锚点投影加逐字屏幕网格，尚未提供带场景深度的完整世界文字平面。
字体使用系统 Microsoft YaHei；不分发字体。常见 Unicode 字符组合有支持，但不等同于 .NET StringInfo 全部规则。
三行排版基于原生字形测量，不是 TMP 排版，超出三行会截断；可选翻译目前单行缩放。
位置距离/字号采用 Source 单位校准，不照搬 Unity 米数；随机高度使用稳定散列，减少重建后的跳动。
柔光是文字 alpha 遮罩经CPU三次分离箱式模糊后的缓存纹理，一层柔光加一层清晰字，不是 TMP SDF/HDR/Bloom。
没有引入 TMP 材质、Unity 库、物理射线、场景深度或光照。
材质、字体和游戏色调映射不同，因此不宣称逐像素一致。

## 安装

退出游戏和 Host，替换 bin/neko/plugins/L4D2DangoMusic.dll。
要套用整套外观，使用 ZIP source/scripts/install.ps1：保留原播放器/世界模式/offset，备份配置，应用新视觉参数。
该脚本 offset 默认500，可用 -OffsetMs 指定当前值。
手动只换DLL会继续尊重旧文件中的字色、翻译、描边等设置；请一并对照新的 config.example.json。
旧 displayMode=character/word/line 不再控制显字，本版统一 Peak 全句布局+按词显字；使用 pop / wiggle 控制效果。

## 验证

Linux 原有回归和新增 Peak 动画测试已执行；覆盖同词同时间、弹出曲线、8Hz时间桶、CJK分组、换行、400ms退场、模糊及靠近后退。
x86 DLL 和 Windows 模拟宿主已交叉编译。游戏中的视觉、同步、退出和帧时间尚待实机验收。
