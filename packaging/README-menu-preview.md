# L4D2DangoMusic @VERSION@ · 菜单重构测试包

本包基于 v0.9.7 和已验收的视觉预览，保留全部外观选项，重新整理菜单，新增“恢复默认外观”和“恢复全部设置”。这是测试构建，不是新的正式 Release。

## 安装

退出游戏，备份配置。已有版本仅替换 `bin/neko/plugins/L4D2DangoMusic.dll`，保留自己的 `bin/neko/plugins/L4D2DangoMusic/config.json`。首次安装先安装 L4N，再将本包 bin 合并到游戏根目录。只启用一份 DangoMusic 插件，删除旧名称的重复 DLL。

包内仅 DLL、默认配置和本 README；无需 .NET 或新增运行时依赖。

## 菜单

L4N 中选择 L4D2DangoMusic，按 1 打开面板。数字键选择，0 返回，`/` 或 Esc 关闭；长列表用 `-` / `=` 翻页。修改立即生效并留在当前页。

主菜单固定为：

1. 歌词显示
2. 外观与预设：17 套预设、8 个收藏、原文、翻译、配色、柔光、逐字明暗及预览
3. 动画与退场：显字、入场、抖动、悬浮、移动、字号平滑、停留与退场
4. 位置与场景：歌词位置与数量、歌名作者位置、复用与回归、墙面/地面挂画
5. 音乐与歌曲信息：音乐来源、同步偏移、歌名作者开关和当前状态
6. 实体跟随：手动、自动分类、实体布局与运动
7. 保存设置：有修改时显示 `[未保存]`
8. 系统与恢复：菜单外观、两种恢复、一起听、版本信息
9. 返回普通歌词：仅实体跟随开启时出现

预设分为新视觉/经典/渐变三页，应用范围固定在各页第一项；点击名字直接应用。收藏按同一范围应用，记录后需保存设置。

“恢复默认外观”立即恢复样式与动画，保留位置、音乐来源、同步偏移、网络设置、实体目标和规则、菜单外观及收藏。“恢复全部设置”需按 1 确认，恢复安装默认配置，清除旧歌词和预览、解除实体目标、关闭联机，仅保留八个收藏；按 2 取消。两种恢复均不自动覆盖配置，仍需主菜单第 7 项保存。

默认外观保持原有暖白、抖动和弹跳，不等于关闭所有动画。挂画背景默认关闭；新视觉效果仍可逐项选择。

一起听、发现、自动搜索及进度应用均默认关闭；关闭总开关不会绑定或轮询 P2P。普通 DLL 不包含诊断工具。已完成回归、恢复范围、菜单导航与字库检查、网络关闭隔离检查和 Windows x86 构建；游戏内菜单及视觉效果待实测。
