# L4D2DangoMusic @VERSION@ · 网易云原生测试版

本包基于正式版 v0.9.5 增加网易云原生播放信息读取和歌词获取。只有插件 DLL、默认配置和本文档，不包含 .NET、桥接 EXE、源码或构建工具。

## 安装与升级

1. 退出游戏，确保 L4N 已安装且能正常使用。
2. 首次安装将 bin 合并到游戏根目录，默认选择网易云音乐。
3. 升级仅替换 bin/neko/plugins/L4D2DangoMusic.dll，保留自己的 bin/neko/plugins/L4D2DangoMusic/config.json。
4. 网易云客户端播放一首歌曲，游戏菜单“显示与歌词信息 → 音乐来源 → 网易云音乐”，然后回主菜单保存设置。此前选择了“Windows 音乐会话”也要重新选择网易云。
5. 请仅启用一份歌词 DLL。旧 DangoMediaBridge.exe 可删除，网易云原生通道不启动它。

本包仍可选择 LX 本地 API。QQ、酷狗、Spotify、Tidal 等 Windows SMTC 通道目前需要另一个完整桥接包，不包含在本小包中。

## 获取方式与限制

原生 C++ 读取当前用户的 `%LOCALAPPDATA%\NetEase\CloudMusic\cloudmusic.elog`，提取歌曲 ID、歌名/作者/时长、播放/暂停、拖动进度；按歌曲 ID 从网易云获取 LRC、原生翻译和接口返回时的 YRC 逐字时间。歌词请求在后台，不阻塞绘制。

不需要网易云向 Windows 注册 SMTC，不需要 BetterNCM，不注入音乐客户端，不需要登录接口或填写 Cookie。只解析所需字段，不复制或上传原始日志、签名音乐地址等内容。

要求客户端实际生成兼容的 elog 播放事件。参考格式用于部分网易云 3.x 客户端，尚不能保证所有版本。可先在网易云切换一首歌，让当前播放事件写入日志。

日志缺失/不可读、没有播放事件、客户端已关闭、网络歌词请求失败等会显示或记录具体原因。进程 ID 和创建时间用于防止把上次关闭的旧歌曲当成当前播放。没有歌词或没有真实逐字时间时，继续使用原有整句/估算选项。

## 显示功能

保留正式版的世界/屏幕歌词、翻译、颜色与动画、墙面/地面挂画和实体跟随，以及所有位置和退场设置。设置即时生效，主菜单“保存设置”保留下次使用。`1..9` 选择、`0` 返回、`Esc` 或 `/` 关闭。

## 诊断

插件日志：`bin/neko/plugins/L4D2DangoMusic.log`。检索 `Netease elog track` 和 `Netease native lookup`，分别表示解析到当前歌曲、完成按 ID 获取歌词。原生通道不生成 media-state JSON，也不需要 media-bridge.log。

如果仍然没有歌曲，请反馈插件日志和网易云客户端版本；无需直接上传完整 cloudmusic.elog，它可能包含与本插件无关的客户端内容。

这是测试包，已通过编码/分段读取、暂停/恢复/seek/退出、歌词/YRC/翻译解析回归和 Windows x86 构建，仍需用户实机验证日志格式及时间同步。原正式 Release 不变。
