# L4D2DangoMusic @VERSION@ · 正式版

保留歌词、动画、世界/屏幕、挂画和实体跟随，提供网易云原生歌词与可选 LX 一起听。发布为正式版不代表联机或 VAC 安全经过验证。

安装包只有 bin 和 README：一个插件 DLL 和默认配置，无需 .NET、桥接 EXE 或额外 Steam DLL。

@DISCLAIMER@

## 安装与音乐来源

退出游戏，将 bin 合并到游戏根目录。升级只替换 bin/neko/plugins/L4D2DangoMusic.dll，保留自己的 config.json；只启用一份歌词插件。

“显示与歌词信息 → 音乐来源”仅提供以下已实现入口，未实现的来源不显示：

- 自动（LX 优先）：LX 本地 API 不可用时尝试网易云，每 5 秒检查 LX 恢复。LX 暂停或无歌曲但接口仍连接时，不自动回退。
- LX 本地 API：落雪开启官方 OpenAPI，默认 127.0.0.1:23330。
- 网易云音乐：原生读取本机 cloudmusic.elog，按歌曲 ID 获取歌词，无需 Windows 音乐会话。

旧配置中不受支持的来源会迁移为自动。

## 自动一起听（仅 LX）

入口：“更多设置 → 一起听与播放控制”。

1. 两端安装相同版本，加入同一游戏，开启各自 LX 的 OpenAPI。
2. 打开“同局玩家与插件发现”，确认其他真人玩家已响应。默认开启发现，但一起听默认关闭。仅探测同局最多三人，排除自己和 bot，不扫描好友。
3. 各端开启“一起听”，会同时开启进度应用。插件自动选出房主；需要更换时，任意参与者选择“我来当房主”。后收到并基于当前房间状态作出的声明覆盖前声明，同时声明会确定性收敛。
4. 跟随端默认使用 LX 官方 Scheme 搜索并播放房主歌曲，通过歌名、歌手、时长提高版本准确性。实际歌曲匹配后才校时和应用进度；错误版本不会收到房主进度跳转。
5. 可关闭“应用房主进度”先观察，或关闭自动切歌、自己选择同一版本。需要跨次保留时返回主菜单保存设置。

Scheme 使用官方 lxmusic://music/searchPlay?data=…，要求 LX 安装并注册协议。系统接收请求不代表搜索成功；搜索后最长等待 20 秒验证，每次失败冷却 30 秒，最多三次，菜单可手动重试。Scheme 搜索会直接播放 LX 选出的候选歌曲，插件无法在播放前读取候选列表；已交给 LX 的请求也无法撤回。

参与者关闭一起听、切换网易云或离开时重新分配房主。来源变化和房主变化会清除未发送的旧控制并重新握手。只传歌曲元数据、进度和状态，不分发音频、下载链接或账号资料。网易云仅显示本机歌词，不参与一起听。

协议升级为 v3，两端必须同时更新；旧版手填 role/host/peers 不再决定网络授权，当前游戏名单和插件双向握手共同决定允许对象。

## 验证范围与日志

播放控制页提供播放、暂停、停止归零、跳转以及当前曲目 Scheme 回调测试。Steam 测试保留真实 SteamID 自指、本地 SocketPair 和内存多玩家模拟，已删除虚拟 User 创建及相关用户/pipe 生命周期调用。

已有用户日志验证 LX 播放/暂停/跳转、真实 SteamID 自指和 SocketPair；网易云独立分支也已验证。新增同局名单、自动选主及 Scheme 自动切歌通过静态接口核对、协议模拟和编译检查，尚未进行真实多账号联机实测；不保证 VAC 安全。
