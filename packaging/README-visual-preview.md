# L4D2DangoMusic @VERSION@ · 视觉测试包

包含七套新预设：极简字幕、霓虹夜行、落日胶片、冰晶、水墨、呼吸悬浮、美术馆；新增八个自定义槽位，可整套或只应用颜色、动画、排版。

@DISCLAIMER@

## 安装

退出游戏，仅替换 bin/neko/plugins/L4D2DangoMusic.dll，保留自己的 config.json，只启用一份歌词插件。首次安装将 bin 合并到游戏根目录，并先安装 L4N。包内仅 DLL、默认配置和 README，无额外运行时依赖；测试前建议备份配置。

本包以 v0.9.7 为基础：联机全部默认关闭，旧版权限不会自动恢复，正式 DLL 不含诊断测试。视觉预设不会修改网络、来源、同步偏移、跟随规则或锚点位置。

## 使用

- 歌词颜色 → 七套视觉预设与自定义收藏：选择七套风格、分项应用或保存自己的搭配。
- 显示与歌词信息 → 原文与翻译样式：调整原文大小倍率/透明度、翻译大小/透明度/间距、独立颜色与 RGB。
- 逐字明暗与动态柔光：设置未唱、已唱亮度及当前词高光；挂画可选柔光和描边。
- 动画、速度与停留 → 停留与退场：原有、淡出、上浮、缩小或逐字散去；可选距离尺寸平滑。
- 整句悬浮与入场幅度：设置浮动周期、幅度、弹跳强度和柔和渐入。
- 页面内预览会显示原文和翻译并循环退场，退出后恢复当前歌曲，不控制音乐。

自定义槽位先记录在内存，需返回主菜单“保存设置”才会跨次保留。新效果默认关闭，原有配色和自定义项保留。原文与翻译共用退场时间，实体跟随仍单句替换；新退场不会延长歌词寿命。

逐字明暗只按真实逐字时间工作；无时间轴仍使用原有整句或估算渐显。若要同时看见未唱/已唱文字，可关闭按时间显字。动态柔光需要原有柔光开启。挂画保持真实表面透视，尺寸平滑适用于悬浮/屏幕/实体字幕及歌名作者。

已完成回归、词持续时间、预设隔离与持久化、菜单字库、联机关闭计数以及 Windows x86 编译检查；游戏内视觉与性能仍待实测。本包为预览，不是新的正式 Release。
