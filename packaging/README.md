# L4D2DangoMusic @VERSION@ · 多平台歌词测试版

《求生之路 2》的原生 L4N 歌词插件。支持 LX / BLF 本地 API、Windows 媒体会话、多平台同步歌词、逐字歌词与翻译、世界/屏幕歌词、墙面和地面挂画，以及可选的手动/自动实体跟随。运行在 32 位游戏进程，不依赖 LDB、DXVK、Unity 或另行下载的游戏 DLL。

## 安装与升级

1. 完整退出游戏，先确认已安装并能正常使用 L4N。
2. 首次安装，将本包 `bin` 文件夹合并到游戏根目录，例如 `D:\Steam\steamapps\common\Left 4 Dead 2`。
3. 升级时替换 `bin/neko/plugins/L4D2DangoMusic.dll` 和配置子目录的 `DangoMediaBridge.exe`，保留自己的 `bin/neko/plugins/L4D2DangoMusic/config.json`。
4. 移出旧 `LDBDangoMusic.dll`、改名副本及旧 Host 歌词插件，只加载一份本插件，然后重启游戏。

安装后的文件：

```text
游戏根目录/
└─ bin/neko/plugins/
   ├─ L4D2DangoMusic.dll
   └─ L4D2DangoMusic/
      ├─ config.json
      └─ DangoMediaBridge.exe
```

L4N 和音乐播放器需自行安装。本包仅包含 bin 与本文档，不附带游戏资源、源码、构建工具或测试程序。

## 开始使用

LX 用户开启支持 `/status` 和 `/lyric-all` 的本地 API，默认地址 `127.0.0.1:23330`。网易云等客户端用户在“显示与歌词信息 → 音乐来源”指定客户端，并确认 Windows 媒体控件有歌曲和进度。播放有同步歌词的歌曲，在 L4N 菜单选择 L4D2DangoMusic。

菜单设置即时生效，主菜单第 7 项“保存设置”保留下次使用。实际修改显示未保存，写入成功后显示已保存。`1..9` 选择，`-` / `=` 翻页，`0` 返回，`Esc` 或 `/` 关闭。菜单外观页可调整背景、透明度、字号、位置和 F10 快捷键。

开启为绿色，关闭为红色，汇总的部分开启为黄色；进入子菜单的入口为白色，文字状态始终保留。

## 歌词、挂画与退场

普通歌词支持 1～9 个轮换位置，歌名和作者独立定位，提供固定预览、翻译、逐字渐显、弹跳、抖动、柔光与同步偏移。同步偏移正数提前、负数延后。没有逐字时间轴时，可选择整句或估算渐显。

场景挂画可自动寻找墙面/地面，或用 F8 手动放置，支持背景、复用、文字布局及地面文字随视角转向。挂画及背景、复用、地面转向默认关闭。无新表面时可按设置回退为固定世界歌词。

普通旧句按全局停留与退场时间自然淡出；挂画默认沿用全局时间，可显式启用独立时间。编号复用、面板容量和实体设置变化不会直接覆盖正常退场。暂停、停止、断开播放器、切歌、切图和拖动进度仍会清理旧内容。

“动画、速度与停留 → 歌词移动与实体平滑”提供可选的全局换句移动，默认关闭；新句从上一句位置移动到自己的编号位置。实体平滑默认开启。共有先快后慢、匀速、先慢后快、缓入缓出和回弹曲线，默认先快后慢、350ms。

## 实体跟随与自动追踪

“更多设置 → 实体持续跟随歌词”可瞄准锁定目标，关闭菜单后仍继续跟随。默认显示当前歌词，也可切换固定示例。“位置与大小（固定预览）”可调整左右、高度、前后偏移与大小；“整句上下往复”默认关闭，周期默认 0.5 秒、幅度上下各 1 游戏单位，支持 ±0.1 调整。

实体字幕只保留当前一句，换句直接替换原文和翻译，没有旧句额外停留与退场淡散。实体位置、大小、上下往复及手动目标仅本次会话有效。

“更多设置 → 自动实体追踪（永久规则）”按特感、队友、物品和其他实体分类，选择范围内最近的有效目标，默认全部关闭。可对 Tank、Boomer、Zoey、Gnome 等类型单独设置，也可瞄准识别类型。范围默认 1200，在瞄准页调整。

总页和各分类第一页的“一键开关：[开启／部分开启／关闭]”：全部关闭时点击全开，部分或全部开启时点击全关。分类只修改自身；总开关可暂停运行并保留选择。该页末项或主菜单保存后，类型规则与移动动画设置跨游戏保留。

显示优先度：有效手动实体 → 有效自动实体 → 已开启挂画 → 普通世界/屏幕歌词。没有实体时回退，自动规则继续检测。主菜单第 9 项“返回普通歌词”停止手动与自动跟随，保留自动类型选择。

可搬物拿起/丢出时保留锁定并尝试恢复；Gnome 另外支持有模型编号和持有关系证明的表示切换。实体数据来自网络位置，不包含精确骨骼、手部附件、静态地图道具枚举和动态遮挡。信息不足或候选不唯一时不猜测挂点。自动 Gnome 物理道具识别需要模型名或本地图的世界模型关联。

## 可选彩色效果

“歌词颜色 → 彩色、混色与渐变”保留纯色及原有六套预设，并增加双色渐变、逐字彩虹、流动渐变和双色呼吸；提供海盐落日、极光薄荷、樱桃汽水、霓虹光谱四套配色。

第二色沿用光晕颜色；即使关闭柔光，也可用于混色。强度与流动速度以 0.1 调整，可在颜色页进入示例预览。实际歌词和翻译在普通、实体及挂画模式均可使用新着色，不改变退场或追踪逻辑。新效果默认关闭，保存后保留；选择原有预设可恢复纯色。

## 排查

- 没有歌词：检查音乐 API、端口及歌曲是否有同步歌词；检查是否仍在跟随屏幕外的实体，可用主菜单第 9 项返回普通歌词。
- 双份歌词或重复菜单：移出所有旧副本后重启游戏。
- 挂画失败：尝试更平整、更大的实墙或较小尺寸；射线主要处理世界几何，动态遮挡有接口限制。
- 实体不可跟随：检查目标类别、网络姿态、休眠及地图构建是否受支持；静态装饰物不一定是网络实体。
- 主日志：`bin/neko/plugins/L4D2DangoMusic/L4D2DangoMusic.log`。实体只读诊断可选导出同目录 `entities.jsonl`；正常使用不需要持续诊断。

## 多平台歌词测试

本安装包以正式版 v0.9.5 为基准，新增 Windows 音乐会话桥接，不是新的正式版 Release。

升级时除插件 DLL 外，还需替换 bin/neko/plugins/L4D2DangoMusic/DangoMediaBridge.exe，保留自己的 config.json。桥接自带运行时，需要 Windows 10 2004+ x64，无须另装 .NET。

网易云验证：先在 Windows 媒体控件确认当前歌曲和播放进度；游戏内“显示与歌词信息 → 音乐来源 → 网易云音乐”，再保存设置。未提供 SMTC 的客户端版本无法直接读取。默认自动模式仍优先 LX 本地 API，API 断开后尝试 Windows 会话。

已接入网易云、QQ 音乐、酷狗、LRCLIB 歌词搜索，保留歌词源翻译和可用的逐字时间；没有逐字时间时继续使用整句/估算选项。网易云在线接口探测通过，Windows 到游戏的完整链路待用户验证；其他来源完成接口移植和模拟响应测试，未实机验证。Spotify、Tidal 等提供 SMTC 的客户端也可选。

桥接随游戏启动/退出，不监听网络端口；配置子目录的 media-bridge.log 和 media-state-进程号.json 可用于排查。后台搜索按歌曲隔离，切歌、暂停、关闭客户端继续遵守原有清理规则。
