# L4D2DangoMusic @VERSION@ · 角色台词实验 build 1

来源分支 `experiment/npc-dialogue`，从已归档实体实验独立开发；不包含挂画布局测试分支的新功能，不更新正式 Release。

## 台词跟随测试

1. 退出游戏，仅替换本包 DLL，保留原配置，确保只加载一份 Dango 插件。
2. 在游戏中开启原生对话字幕，确认能够看到角色台词。进入地图后，L4N → L4D2DangoMusic → 更多设置 → 实验：角色台词跟随。
3. 开启“采集与跟随（需游戏字幕）”，等待菜单显示字典数量大于 0、字幕消息 hook ready。默认简体中文，缺失条目回退英文；可切换 English 或重新载入字典。
4. 先在“测试角色”选择地图内实际存在的角色，测试唯一实体匹配和气泡绘制。该测试明确标记为 synthetic，不证明真实字幕已经接入。自己第一人称角色的头顶通常不在视野内，建议选队友。
5. 再触发真实角色对白。最多同时显示八个角色，每个实体保留最新一句；未知名字、同角色多实体、死亡/休眠/失效目标不猜测挂载。当前是实体网络位置加高度偏移，不是精确头骨；不要求 LX 音乐 API。
6. 测试后点“导出状态与实体快照”，等待数秒，再关闭采集。提供同一目录的 L4D2DangoMusic.log、dialogue.jsonl、entities.jsonl。新字幕记录标记 dialogue_build=1，实体诊断帧 diagnostic_build=7。

字幕字典优先读取插件数据目录 caption-resources 中的 subtitles_schinese.dat / closecaption_schinese.dat（可选覆盖），然后读取游戏 DLC/本体 resource 下的散装文件和 pak01_dir.vpk 及其分包。支持原生 VCCD v1 与 VPK v1/v2，不附带或分发游戏字幕资源。自定义 addon 字幕若未被自动读取，可将实际 .dat 放入上述覆盖目录后重新载入。

开关、语言、高度和气泡显示均为本次会话实验设置，不写入持久化配置。原生字幕保持游戏原样，插件不修改游戏字幕开关。角色名是否实际包含在每条字幕中、旧战役的角色编号与真实回调仍需实机验证。字幕名字缺失时只记录，不按时间猜人。

输出都在 bin/neko/plugins/L4D2DangoMusic/，dialogue.jsonl 追加记录，达到 32 MiB 停止写诊断；后续测试前退出游戏并改名保留旧文件。关闭实验后可以继续使用原歌词功能。

《求生之路 2》原生 L4N 歌词插件。支持 LX / BLF 本地 API、翻译、逐字动画、固定世界歌词和场景挂画歌词。

## 安装

1. 退出游戏，确认已安装并能正常使用 L4N。
2. 将压缩包内的 `bin` 文件夹合并到游戏根目录，例如：
   `D:\Steam\steamapps\common\Left 4 Dead 2`。
3. 首次安装复制全部文件。升级时替换 `bin/neko/plugins/L4D2DangoMusic.dll`，保留自己的 `bin/neko/plugins/L4D2DangoMusic/config.json`，避免覆盖设置。
4. 将旧的 `LDBDangoMusic.dll`、本插件的改名副本及旧 Host 歌词插件移出插件加载目录，再完整重启游戏。只保留一份歌词插件。

安装后的文件位置：

```text
游戏根目录/
└─ bin/neko/plugins/
   ├─ L4D2DangoMusic.dll
   └─ L4D2DangoMusic/config.json
```

本插件运行于 32 位游戏进程，不依赖 LDB、DXVK、Unity 或额外下载的游戏 DLL。L4N 和音乐播放器需要自行安装。

## 使用

- 开启兼容 LX / BLF 的本地音乐 API，默认地址 `127.0.0.1:23330`，需要支持 `/status` 和 `/lyric-all`。
- 在 L4N 菜单进入 **L4D2DangoMusic**，调整翻译、颜色、动画、歌词位置和同步偏移。
- 菜单由插件原生 HUD 绘制，数值自动刷新。`1..9` 选择，`-` / `=` 翻页，`0` 返回，`Esc` 或 `/` 关闭；关闭菜单也会结束位置预览。
- “更多设置 → 菜单外观”提供四套背景、透明度、字号和菜单位置。选择透明度或字号后用 `-` / `=` 调节；位置页用方向键移动，`-` / `=` 调整步宽。F10 默认关闭，可选开启。
- 菜单外观和歌词设置均通过主菜单第 7 项“保存设置”保留下次启动。修改后显示 `[未保存]`，写入成功后显示 `[已保存]`。
- 开启“场景挂画歌词”后，可自动寻找前方左右墙面，或按 F8 手动放置。当前句贴墙成功后保持原位，旧句按停留与淡出设置自然消失。
- “显示与歌词信息 → 世界位置与回归 → 复用距离上限”可限制世界歌词换句时复用旧锚点的距离。设当前编号位置的配置距离为 A，默认只复用距相机小于 3A 且仍在视野内的锚点；超出后按预设位置重新放置。支持 1、1.5、2、3、4、5、10 倍，并可保存设置。
- “靠近时后退”用于悬浮世界歌词、歌名和作者，在该组件配置距离的 60% 以内持续推远；固定墙面挂画保持贴墙。“无逐字时间轴 → 估算渐显”独立于真实逐字时间显字开关。
- “显示与歌词信息 → 世界位置与回归 → 长句回到视野 → 自定义秒数”可按 0.1 秒微调，最大 300 秒；0 关闭，原有 3/5/10 秒预设仍保留。
- 场景挂画与挂画背景默认关闭。背景可在“场景挂画 → 挂画外观与维护 → 背景面板”开启，升级时保留已有配置中的选择。无合适墙面的新句可回退为固定世界歌词。
- 暂停、停止或播放器断开时隐藏歌词。自动切歌会重新复核歌词数据。

## 排查

- 没有歌词：检查播放器 API、端口和歌曲是否含同步歌词。
- 双份歌词：移出所有旧副本后重启游戏。
- 同步偏差：调整“同步偏移”，正数提前、负数延后。
- 挂画失败：尝试更平整、更大的实墙或较小挂画尺寸。场景接口依赖受支持的游戏构建；射线遮挡针对世界几何，不保证动态门、角色或道具遮挡。
- 日志：`bin/neko/plugins/L4D2DangoMusic/L4D2DangoMusic.log`。
